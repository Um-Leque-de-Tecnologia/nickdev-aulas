API no ar ✅

O desafio resolvido com o tema "receitas": dois arquivos escritos por você, duas linhas de configuração e três rotas respondendo. É esta a cara de uma entrega completa da aula 01.

Os dois arquivos que você escreve
ReceitaController.java
package br.edu.faculdade.receitas;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;
import java.util.List;

@RestController
public class ReceitaController {

  private final List<Receita> receitas = List.of(
      new Receita("Bolo de fubá",     "Doce",    50, true),
      new Receita("Strogonoff",      "Salgado", 35, false),
      new Receita("Sopa de abóbora", "Salgado", 40, true),
      new Receita("Pudim",           "Doce",    70, true));

  @GetMapping("/boas-vindas")
  public String boasVindas() {
    return "API de receitas da Ana — no ar!";
  }

  @GetMapping("/destaque")
  public Receita destaque() {
    return receitas.get(0);
  }

  @GetMapping("/receitas")
  public List<Receita> todas() {
    return receitas;
  }
}

O que este código prova

Você entregou o controle

Não existe new ReceitaController() em lugar nenhum. Quem criou o objeto foi o Spring, no start, porque leu a etiqueta @RestController.

JSON de graça

O record volta como objeto e o Jackson serializa sozinho, com Content-Type: application/json correto. Zero linha de conversão escrita por você.

Você discordou do padrão

A porta 8081 no lugar da 8080 mostra que o application.properties sobrescreveu a autoconfiguração — que é exatamente pra isso que ele existe.

As duas perguntas do README

1. Quem criou o objeto do controller, e quando?

O Spring, durante a subida da aplicação. A anotação @ComponentScan — que vem embutida no @SpringBootApplication — varreu o pacote br.edu.faculdade.receitas, encontrou a classe etiquetada com @RestController, instanciou um objeto dela e guardou no contêiner. Quando a requisição chegou, o Spring chamou o método naquele objeto, que já existia desde o start.

2. Como o Spring soube converter o objeto em JSON?

A biblioteca Jackson veio dentro do spring-boot-starter-web. Na subida, a autoconfiguração do Spring Boot verificou que ela estava disponível e a registrou como conversora padrão. Como o método é de um @RestController, o retorno vira corpo da resposta — e o Jackson leu os campos do record pra montar o JSON.
