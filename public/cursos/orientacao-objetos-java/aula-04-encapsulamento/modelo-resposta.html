Livro.java encapsulado 🔒✅

A classe Livro com atributos private, getters e setters validados, dois construtores (um chamando o outro com this(...)), um método sobrecarregado, um contador static e uma constante final — mais a classe de teste e a saída real do terminal.

Código & saída
Livro.java
// desafio da aula 04 · orientação a objetos com java
public class Livro {
  private String titulo;
  private String autor;
  private double preco;
  private boolean emprestado;

  private static int totalDeLivros = 0;
  public static final double PRECO_MINIMO = 0.0;

  public Livro(String titulo, String autor, double preco) {
    setTitulo(titulo);
    this.autor = autor;
    setPreco(preco);
    this.emprestado = false;
    totalDeLivros++;
  }

  public Livro(String titulo, String autor) {
    this(titulo, autor, PRECO_MINIMO);
  }

  public String getTitulo() { return titulo; }
  public String getAutor() { return autor; }
  public double getPreco() { return preco; }
  public boolean isEmprestado() { return emprestado; }

  public void setTitulo(String titulo) {
    if (titulo == null || titulo.isBlank()) {
      throw new IllegalArgumentException("Título não pode ser vazio");
    }
    this.titulo = titulo;
  }

  public void setPreco(double preco) {
    if (preco < PRECO_MINIMO) {
      throw new IllegalArgumentException("Preço não pode ser negativo");
    }
    this.preco = preco;
  }

  public void emprestar() { emprestado = true; }
  public void devolver() { emprestado = false; }

  public double calcularDesconto(double percentual) {
    return preco - (preco * percentual / 100);
  }

  public double calcularDesconto() {
    return calcularDesconto(10);
  }

  public static int getTotalDeLivros() { return totalDeLivros; }
}
TesteLivro.java + terminal
public class TesteLivro {
  public static void main(String[] args) {
    Livro duna = new Livro("Duna", "Herbert", 89.90);
    Livro orwell = new Livro("1984", "Orwell");

    System.out.println(duna.getTitulo() + " — R$ " + duna.getPreco()
      + " — total: " + Livro.getTotalDeLivros());
    System.out.println(orwell.getTitulo() + " — R$ " + orwell.getPreco()
      + " — total: " + Livro.getTotalDeLivros());

    System.out.println("Desconto padrão: R$ " + duna.calcularDesconto());
    System.out.println("Desconto 25%: R$ " + duna.calcularDesconto(25));

    try {
      duna.setPreco(-10);
    } catch (IllegalArgumentException e) {
      System.out.println("Bloqueado: " + e.getMessage());
    }
  }
}
$ javac Livro.java TesteLivro.java $ java TesteLivro Duna — R$ 89.9 — total: 1 1984 — R$ 0.0 — total: 2 Desconto padrão: R$ 80.91 Desconto 25%: R$ 67.425 Bloqueado: Preço não pode ser negativo
Por que essa solução funciona

Atributos fechados

Todo estado é private. A única forma de ler ou mudar é passando pelos métodos — e eles decidem o que aceitar.

this sem ambiguidade

Parâmetro e atributo com o mesmo nome deixam de ser um problema: this.preco é sempre o atributo do objeto atual.

Um construtor chama o outro

this(titulo, autor, PRECO_MINIMO) evita repetir a mesma inicialização em dois lugares.

Sobrecarga real

calcularDesconto() e calcularDesconto(double) coexistem — o Java escolhe pelos parâmetros passados na chamada.

static é da classe

totalDeLivros é uma cópia só, somada em todo construtor — por isso chega a 2 mesmo com dois objetos diferentes.

final nunca muda

PRECO_MINIMO é constante: o compilador barra qualquer tentativa de reatribuí-la depois de criada.

Checklist batido
  • Todos os atributos de Livro são private
  • Getters pra todos, setters com validação em titulo e preco
  • this usado nos setters e no construtor
  • Dois construtores, o de 2 parâmetros chamando o de 3 com this(...)
  • calcularDesconto sobrecarregado (com e sem parâmetro)
  • Contador static + constante static final
  • TesteLivro.java rodando e mostrando o comportamento completo
