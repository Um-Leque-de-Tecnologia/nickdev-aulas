antes da palavra difícil · uma agenda de telefone

Duas maneiras de anotar contatos

Maneira 1: listas separadas

Uma folha só com os nomes. Outra só com os telefones. Outra só com os aniversários.

Funciona — desde que você lembre que o terceiro nome é dono do terceiro telefone. Apagou uma linha do meio? Tudo desanda.

Maneira 2: um cartão por pessoa

Cada pessoa tem seu cartãozinho, com nome, telefone e aniversário juntos.

Perdeu um cartão? Perdeu só aquela pessoa. O resto continua certinho.

Essas duas maneiras de arrumar as coisas existem na programação também. Cada jeito de organizar código tem um nome: paradigma. As listas separadas são o estruturado. O cartão com tudo junto é a orientação a objetos — o assunto das próximas 18 aulas.

paradigma estruturado · as listas separadas, em Python

Código como uma sequência de passos

É a maneira 1: o nome do livro numa variável, se ele está emprestado em outra, e uma função solta que mexe nisso. Dados de um lado, ações do outro:

# estilo estruturado: dados soltos + funções que mexem neles nome = "Duna" emprestado = False def emprestar(titulo): print(titulo + " foi emprestado.") emprestar(nome)

Repare: a função emprestar não sabe nada sobre emprestado. Quem precisa lembrar de atualizar essa variável é você, de fora.

paradigma orientado a objetos · ainda em Python

Código como um conjunto de objetos

É a maneira 2, o cartãozinho: tudo que é do livro fica dentro do livro. As informações (chamadas atributos) e as ações (chamadas métodos) moram no mesmo lugar. Aqui o Livro sabe emprestar a si mesmo:

# estilo orientado a objetos: dados + comportamento juntos class Livro: def __init__(self, nome): self.nome = nome self.emprestado = False def emprestar(self): self.emprestado = True print(self.nome + " foi emprestado.") # usando o objeto duna = Livro("Duna") duna.emprestar()

Agora ninguém precisa lembrar de nada de fora: o próprio livro atualiza o seu estado. OO não é coisa de Java — Python também faz.

a ponte · a mesma classe, agora em Java

Então o que muda em Java?

// a mesma Livro da tela anterior, escrita em Java class Livro { String nome; boolean emprestado = false; Livro(String nome) { this.nome = nome; } void emprestar() { emprestado = true; System.out.println(nome + " foi emprestado."); } }

Igual

A ideia é a mesma: classe, atributos, métodos, criar objeto e chamar comportamento.

Diferente

Java exige tipo em tudo (String, boolean), usa { } em vez de indentação e obriga a classe — em Python ela é opcional.

É por isso que a gente começou em Python: o conceito você já viu. Daqui pra frente só muda a escrita.

// a mesma ideia, dois paradigmas

Estruturado × orientado a objetos

Estruturado

Dados soltos + funções que operam sobre eles. Bom pra script pequeno; cresce mal, porque quem lembra das regras é você.

Orientado a objetos

Dados e comportamento agrupados em classes. Cada objeto cuida de si mesmo — mais fácil de crescer e reaproveitar.

Ao longo do curso você vai ver por que sistemas médios/grandes quase sempre usam OO: encapsulamento, herança e polimorfismo (aulas 4, 6 e 7).

por que java · a linguagem do curso

Java é 100% orientado a objetos

  • Tudo (quase) vive dentro de uma classe — inclusive o próprio main
  • Fortemente tipado: o compilador te avisa de muitos erros antes de rodar
  • Roda em qualquer sistema operacional — "escreva uma vez, rode em qualquer lugar"
  • É a linguagem mais usada em sistemas corporativos, Android e back-end
ecossistema java · três siglas que confundem todo mundo

JDK, JRE e JVM

JDK — a oficina inteirao carro mais as ferramentas pra construir carros. É o que você instala pra escrever programas.
JRE — o carro montadomotor, rodas, volante. Dá pra dirigir — ou seja, rodar programas prontos. Não dá pra construir outro.
JVM — o motora peça que de fato faz andar. Existe uma pra Windows, uma pra Mac, uma pra Linux.

São bonecas russas: uma dentro da outra. Você vai escrever programas, então precisa da oficina — instale o JDK. O carro e o motor já vêm dentro.

bytecode · o "meio-termo" do Java

Do código-fonte ao bytecode

Você escreveu um livro em português e quer que o mundo inteiro leia. Em vez de traduzir pra cada idioma, você traduz uma vez pra uma língua que todo tradutor conhece — e cada país tem o seu tradutor local.

Essa "língua do meio" chama bytecode. É por causa dela que o mesmo arquivo .class roda no Windows, no Mac e no Linux sem você mexer em nada.

setup do ambiente · passo 1

Instalar o JDK 21

Baixe o instalador

Em oracle.com/java/technologies/downloads, role até JDK 21 e escolha a aba do seu sistema.

Instale

Windows/macOS: rode o instalador normalmente. Linux: pelo gerenciador de pacotes (ex.: apt) ou extraindo o .tar.gz.

Confira no terminal

Abra o terminal e rode java -version e javac -version — os dois precisam responder 21.

primeiro programa · o clássico

Hello, World!

public class Ola { public static void main(String[] args) { System.out.println("Olá, mundo Java!"); } }

O nome da classe Ola tem que bater com o nome do arquivo Ola.java — regra do Java.

compilar e rodar · pelo terminal, sem atalho da IDE

javac + java

$ javac Ola.java
$ ls
Ola.class  Ola.java
$ java Ola
Olá, mundo Java!

javac compila o .java em bytecode (.class); java manda a JVM executar esse bytecode. O botão ▶ da IDE faz exatamente isso por baixo dos panos.
