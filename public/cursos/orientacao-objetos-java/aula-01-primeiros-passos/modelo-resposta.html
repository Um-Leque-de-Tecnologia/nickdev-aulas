SobreMim.java funcionando ☕✅

Um exemplo completo do desafio: a classe SobreMim pronta, com 3 variáveis de tipos diferentes, 3 println com concatenação, e a saída real de rodar javac + java pelo terminal.

Código & saída
SobreMim.java
// desafio da aula 01 · orientação a objetos com java
public class SobreMim {
  public static void main(String[] args) {
    String nome = "Nicoly";
    int idade = 24;
    boolean gostaDeCafe = true;
    String curso = "Orientação a Objetos com Java";
    String cidade = "João Pessoa";

    System.out.println("Olá, meu nome é " + nome + "!");
    System.out.println("Tenho " + idade + " anos e estou aprendendo Java.");
    System.out.println("Estou estudando " + curso + ", de " + cidade + ".");
    System.out.println("Gosto de café? " + gostaDeCafe);
  }
}
terminal
$ javac SobreMim.java $ ls SobreMim.class SobreMim.java $ java SobreMim Olá, meu nome é Nicoly! Tenho 24 anos e estou aprendendo Java. Estou estudando Orientação a Objetos com Java, de João Pessoa. Gosto de café? true
Por que essa solução funciona

4 variáveis, 4 tipos

String, int e boolean — mostrando que Java é fortemente tipado desde a primeira linha.

Concatenação de verdade

Cada println junta texto fixo com o valor de uma variável usando + — não é só texto "chumbado".

Terminal, não IDE

javac gerou o .class (bytecode) e java pediu pra JVM executar — o fluxo completo, na mão.

E ainda não é OO 👀

Variáveis soltas e comandos em sequência dentro do main: isso é o paradigma estruturado, o mesmo que vimos em Python. A class está aqui só porque o Java obriga — SobreMim não é um objeto. Objeto de verdade começa na aula 03.

Checklist batido
  • JDK 21 e IntelliJ IDEA Community instalados
  • Classe SobreMim com public static void main
  • 4 variáveis (mais que o mínimo de 3), com tipos diferentes
  • 4 System.out.println com concatenação
  • Compilado com javac SobreMim.java
  • Executado com java SobreMim, direto do terminal
  • Pronto pra subir num repositório público no GitHub
