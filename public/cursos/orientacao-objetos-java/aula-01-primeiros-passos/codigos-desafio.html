📁 Preparação

Estrutura do projeto

Depois de criar o projeto no IntelliJ e o arquivo SobreMim.java dentro de src/, a estrutura fica assim:

orientacao-objetos-java/ ├── .idea/ ← configuração da IDE (não mexe) ├── src/ │ └── SobreMim.java ← seu código-fonte ├── out/ ← .class gerados pela IDE (pode ignorar) └── orientacao-objetos-java.iml

Pra compilar pelo terminal (fora da IDE), você vai navegar até a pasta src e rodar os comandos de lá — é onde o SobreMim.java está.

🧩 Esqueleto

SobreMim.java — ponto de partida

Comece daqui e complete com suas informações. Repare que o nome do arquivo (SobreMim.java) tem que bater com o nome da classe (SobreMim).

public class SobreMim {
  public static void main(String[] args) {

✅ Solução comentada

1 · Variáveis + concatenação ★

O ponto-chave do desafio: não é só imprimir texto fixo, é usar variáveis dentro do println, juntando texto e valor com o operador + (concatenação).

String nome = "Nicoly";
int idade = 24;
String curso = "Orientação a Objetos com Java";

// concatenação: texto + variável + texto...
System.out.println("Olá, meu nome é " + nome + "!");

Repare que idade é um número (int), mas o + com uma String do lado converte ele pra texto automaticamente na hora de imprimir.

2 · SobreMim.java completo

Juntando tudo: 3 variáveis de tipos diferentes, 3 println, cada um com concatenação.

public class SobreMim {
  public static void main(String[] args) {
    String nome = "Nicoly";
    int idade = 24;
    String curso = "Orientação a Objetos com Java";
    String cidade = "João Pessoa";

    System.out.println("Olá, meu nome é " + nome + "!");
    System.out.println("Tenho " + idade + " anos.");
    System.out.println("Estou estudando " + curso + ", de " + cidade + ".");
  }
}
Por que static? O método main precisa ser static porque a JVM chama ele sem ter criado nenhum objeto ainda — é o ponto de partida do programa. A gente entende static com calma na aula 04 (encapsulamento).
E isto ainda não é OO 👀 Repare no que o programa faz: variáveis soltas e comandos em sequência, tudo dentro do main. É o paradigma estruturado — o mesmo que vimos em Python no começo da aula. A palavra class está aqui só porque o Java obriga: todo método mora dentro de uma classe. SobreMim não é um objeto — não tem estado próprio e ninguém escreve new SobreMim(). Objeto de verdade, com atributos e comportamento juntos como o Livro dos slides, começa na aula 03.
⌨️ Terminal

3 · Compilar com javac

Dentro da pasta onde está o SobreMim.java:

$ javac SobreMim.java

Se não aparecer nenhuma mensagem de erro, deu certo — e um novo arquivo SobreMim.class (o bytecode) foi criado do lado do .java.

4 · Rodar com java

Agora peça pra JVM executar o bytecode — repare que não tem .class no comando:

$ java SobreMim Olá, meu nome é Nicoly! Tenho 24 anos. Estou estudando Orientação a Objetos com Java, de João Pessoa.

5 · Erros comuns

error: class SobreMim is public, should be declared in a file named SobreMim.java

O nome do arquivo não bate com o nome da classe public. Renomeie um dos dois pra ficarem iguais.

Error: Could not find or load main class SobreMim

Você tentou rodar java SobreMim antes de compilar (não existe o .class ainda), ou está numa pasta diferente de onde ele foi gerado. Rode javac primeiro e confira com ls/dir.

error: ';' expected

Faltou um ponto e vírgula no fim de uma linha — em Java, quase toda instrução termina com ;.
