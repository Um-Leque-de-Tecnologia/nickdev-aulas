Desafio · Aula 01

Ambiente pronto & SobreMim.java ☕

Sua missão: deixar o ambiente Java funcionando de ponta a ponta na sua máquina e provar isso com um programa de verdade — a classe SobreMim, compilada e executada pelo terminal, sem depender do botão ▶ da IDE.

🎯

O objetivo

Instalar JDK 21 e IntelliJ IDEA Community, escrever a classe SobreMim com pelo menos 3 System.out.println usando variáveis e concatenação, compilar com javac e rodar com java no terminal, e publicar num repositório público no GitHub.

Passo a passo
01

Instale o JDK 21

Baixe e instale o JDK 21 pela página oficial da Oracle pro seu sistema operacional. Depois confira no terminal:

$ java -version openjdk version "21.0.x" ... $ javac -version javac 21.0.x

Trave nesse passo? Releia a seção "Instalar o JDK 21" do guia — tem o passo a passo por sistema operacional.

02

Instale o IntelliJ IDEA Community

Baixe a versão Community (gratuita) e crie um novo projeto Java, selecionando o JDK 21 que você acabou de instalar.

Nome sugerido do projeto: orientacao-objetos-java — é nele que você vai criar os arquivos de todas as aulas do curso.

03

Crie a classe SobreMim

Dentro de src/, crie o arquivo SobreMim.java com uma classe que tem um método main. Use pelo menos 3 variáveis e 3 chamadas a System.out.println pra se apresentar:

public class SobreMim {
  public static void main(String[] args) {
    String nome = "seu nome aqui";
    int idade = 0; // troque pela sua idade
    String curso = "Orientação a Objetos com Java";

    System.out.println("Olá, meu nome é " + nome + "!");
    System.out.println("Tenho " + idade + " anos.");
    System.out.println("Estou estudando " + curso + ".");
  }
}

Vale personalizar: troque por informações reais suas — o que você estuda, trabalha, ou por que escolheu programação. O importante é usar variáveis + concatenação (+), não só texto fixo.

Atenção, isto ainda não é OO 👀 — e é de propósito. Repare no que você escreveu: variáveis soltas e comandos em sequência, tudo dentro do main. É exatamente o paradigma estruturado do começo da aula, aquele que a gente viu em Python. A palavra class aparece aqui só porque o Java obriga: todo método precisa morar dentro de uma classe, inclusive o main. SobreMim ainda não é um objeto — não tem estado próprio, e ninguém vai escrever new SobreMim(). Ela é só a porta de entrada do programa. Objeto de verdade — com atributos e comportamento juntos, como o Livro dos slides — começa na aula 03.

04

Compile e rode PELO TERMINAL

Aqui está o pulo do gato do desafio: rode sem usar o botão ▶ da IDE. Abra um terminal na pasta src (ou aponte o caminho) e rode:

$ javac SobreMim.java $ java SobreMim Olá, meu nome é ...! Tenho ... anos. Estou estudando Orientação a Objetos com Java.

Por quê pelo terminal? É a prova de que você entendeu o fluxo .java → javac → .class → java — e não só decorou onde fica o botão verde.

05

Publique no GitHub

Crie um repositório público (ex.: orientacao-objetos-java) e suba o SobreMim.java — pode subir a pasta do projeto do IntelliJ inteira. Se ainda não tem Git instalado/configurado, dá pra fazer também pela interface web do GitHub (criar arquivo direto no navegador).

Meta final: mandar o link do repositório no grupo da turma!

Requisitos mínimos
  • JDK 21 instalado e confirmado com java -version / javac -version
  • IntelliJ IDEA Community instalado, com projeto criado usando o JDK 21
  • Classe SobreMim com método main
  • Pelo menos 3 variáveis usadas em pelo menos 3 System.out.println com concatenação
  • Compilado com javac e executado com java pelo terminal (não só pelo botão ▶)
  • Publicado num repositório público no GitHub
Desafios extras (pra quem quer brilhar ✨)
  • Use variáveis de tipos diferentes (String, int, boolean, double)
  • Adicione um README.md no repositório explicando como compilar e rodar
  • Descubra e use um caractere de escape, tipo \n, dentro de uma String
  • Rode o programa em dois terminais diferentes do seu sistema (ex.: PowerShell e Prompt de Comando, ou bash e zsh)
  • Pesquise o que é o arquivo Ola.class gerado e leia (com um editor de texto) o quanto ele é diferente do código-fonte
