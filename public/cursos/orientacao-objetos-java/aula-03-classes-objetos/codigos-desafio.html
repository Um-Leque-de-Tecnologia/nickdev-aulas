✅ Solução comentada

1 · Livro.java completo

emprestar() só marca disponivel = false e devolve true se o livro estava mesmo disponível — senão, devolve false sem mudar nada.

class Livro {
  String titulo;
  String autor;
  int anoPublicacao;
  boolean disponivel;

  void mostrarFicha() {
    System.out.println(titulo + " — " + autor + " (" + anoPublicacao + ") · "
        + (disponivel ? "disponível" : "emprestado"));
  }

  boolean emprestar() {
    if (disponivel) {
      disponivel = false;
      return true;
    }
    return false;
  }

  void devolver() {
    disponivel = true;
  }
}

O ? : dentro do println é o operador ternário — um jeito curto de escrever um if/else que devolve um valor. Não é obrigatório usar; um if/else comum funciona igual, só ocupa mais linhas.

✅ 2 · Leitor.java

Leitor.java completo ★

O coração do desafio: pegarEmprestado recebe um Livro inteiro como parâmetro, e devolverLivro confere != null antes de mexer em livroAtual.

class Leitor {
  String nome;
  Livro livroAtual;

  boolean pegarEmprestado(Livro livro) {
    boolean conseguiu = livro.emprestar();
    if (conseguiu) {
      livroAtual = livro;
    }
    return conseguiu;
  }

  void devolverLivro() {
    if (livroAtual != null) {
      livroAtual.devolver();
      livroAtual = null;
    } else {
      System.out.println(nome + " não tem nenhum livro emprestado.");
    }
  }
}

Repare que pegarEmprestado reaproveita o próprio livro.emprestar() em vez de mexer direto em livro.disponivel — é o Livro quem decide se pode ser emprestado, o Leitor só pergunta e reage ao resultado. Isso já é um gostinho de encapsulamento, o assunto da aula 04.

✅ 3 · TesteBiblioteca.java

TesteBiblioteca.java (main)

public class TesteBiblioteca {
  public static void main(String[] args) {
    Livro duna = new Livro();
    duna.titulo = "Duna";
    duna.autor = "Frank Herbert";
    duna.anoPublicacao = 1965;
    duna.disponivel = true;

    Livro hobbit = new Livro();
    hobbit.titulo = "O Hobbit";
    hobbit.autor = "J.R.R. Tolkien";
    hobbit.anoPublicacao = 1937;
    hobbit.disponivel = true;

    Leitor nicoly = new Leitor();
    nicoly.nome = "Nicoly";

    Leitor outro = new Leitor();
    outro.nome = "Marcos";

    System.out.println(nicoly.nome + " tentando pegar Duna: " + nicoly.pegarEmprestado(duna));
    System.out.println(outro.nome + " tentando pegar Duna também: " + outro.pegarEmprestado(duna));

    duna.mostrarFicha();

    nicoly.devolverLivro();
    duna.mostrarFicha();

    outro.devolverLivro(); // nunca pegou nada — cai no else, não explode
  }
}
⌨️ Terminal

4 · Compilando as três classes

Dentro da pasta onde estão os três arquivos, compile todos de uma vez:

$ javac Livro.java Leitor.java TesteBiblioteca.java

Dá pra compilar só o arquivo principal também — o javac segue as dependências sozinho: javac TesteBiblioteca.java já compila Livro.java e Leitor.java por trás, se eles estiverem na mesma pasta.

5 · Rodando

Só a classe com main é executável — Livro e Leitor não têm main, então não dá pra rodar java Livro:

$ java TesteBiblioteca Nicoly tentando pegar Duna: true Marcos tentando pegar Duna também: false Duna — Frank Herbert (1965) · emprestado Duna — Frank Herbert (1965) · disponível Marcos não tem nenhum livro emprestado.

6 · Erros comuns

Exception in thread "main" java.lang.NullPointerException: Cannot invoke "Livro.devolver()" because "this.livroAtual" is null

Aconteceu porque devolverLivro() chamou livroAtual.devolver() sem antes conferir if (livroAtual != null). É exatamente o erro que o passo 03 do desafio pede pra você evitar.

error: class Livro is public, should be declared in a file named Livro.java

Se você marcar Livro ou Leitor como public class, o nome do arquivo precisa bater exatamente com o nome da classe. Nas classes auxiliares (que não têm main), nem precisa de public — só class Livro { ... } já funciona, contanto que o arquivo se chame Livro.java.

error: cannot find symbol
  symbol:   method emprestar()
  location: variable duna of type Livro

Geralmente é erro de digitação no nome do método, ou o método foi criado numa classe diferente da que você está chamando. Confira se Livro.java e Leitor.java estão na mesma pasta do arquivo que você está compilando.

error: incompatible types: Livro cannot be converted to boolean

Aconteceu de tentar usar o retorno de um método void (que não devolve nada) como se ele devolvesse um valor — ou o contrário, ignorar um retorno esperado. Confira a assinatura do método (o que vem antes do nome) pra saber o que ele realmente devolve.
