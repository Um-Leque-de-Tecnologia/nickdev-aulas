Código & saída
01 · Classificador de idade
ClassificadorIdade.java
import java.util.Scanner;

public class ClassificadorIdade {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Digite a idade: ");
    int idade = leitor.nextInt();

    if (idade <= 11) {
      System.out.println("Criança");
    } else if (idade <= 17) {
      System.out.println("Adolescente");
    } else if (idade <= 59) {
      System.out.println("Adulto");
    } else {
      System.out.println("Idoso");
    }
  }
}
terminal
$ javac ClassificadorIdade.java $ java ClassificadorIdade Digite a idade: 67 Idoso
02 · Calculadora simples
CalculadoraSimples.java
import java.util.Scanner;

public class CalculadoraSimples {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Primeiro número: ");
    double a = leitor.nextDouble();
    System.out.print("Segundo número: ");
    double b = leitor.nextDouble();
    System.out.print("Operação (+, -, *, /): ");
    char operacao = leitor.next().charAt(0);

    double resultado = 0;
    switch (operacao) {
      case '+': resultado = a + b; break;
      case '-': resultado = a - b; break;
      case '*': resultado = a * b; break;
      case '/': resultado = a / b; break;
      default: System.out.println("Operação inválida"); return;
    }
    System.out.println("Resultado: " + resultado);
  }
}
terminal
$ javac CalculadoraSimples.java $ java CalculadoraSimples Primeiro número: 10 Segundo número: 4 Operação (+, -, *, /): / Resultado: 2.5
05 · Pares em um array
ParesNoArray.java
import java.util.Scanner;

public class ParesNoArray {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Quantos números? ");
    int quantidade = leitor.nextInt();

    int[] numeros = new int[quantidade];
    for (int i = 0; i < numeros.length; i++) {
      System.out.print("Número " + (i + 1) + ": ");
      numeros[i] = leitor.nextInt();
    }

    System.out.print("Pares: ");
    for (int i = 0; i < numeros.length; i++) {
      if (numeros[i] % 2 == 0) {
        System.out.print(numeros[i] + " ");
      }
    }
  }
}
terminal
$ javac ParesNoArray.java $ java ParesNoArray Quantos números? 5 Número 1: 3 Número 2: 8 Número 3: 11 Número 4: 4 Número 5: 7 Pares: 8 4
Recap dos 6 exercícios

1 · Classificador de idade

Cadeia de if/else if/else — cada faixa checa só o limite de cima.

2 · Calculadora simples

switch num char, com default tratando entrada inválida.

3 · Média e situação

Operadores aritméticos com double, evitando o problema da divisão inteira.

4 · Tabuada

for clássico, contando de 1 a 10.

5 · Pares em um array

Array preenchido e depois percorrido em dois laços for separados, usando %.

6 · Contador com while

do-while, porque precisa ler o primeiro número antes de ter o que comparar.

Checklist batido
  • Seis classes, uma por exercício, cada uma com seu próprio main
  • Todas as entradas lidas com Scanner — nada de valor fixo no código
  • Tipos primitivos certos pra cada dado (int pra idade e quantidade, double pra notas e resultados, char pra operação)
  • Decisão com if/else (exercícios 1 e 3) e com switch (exercício 2)
  • Repetição com for (exercícios 4 e 5) e com while/do-while (exercício 6)
  • Array declarado, preenchido e percorrido corretamente (exercício 5)
  • Compilado com javac e executado com java, pelo terminal
