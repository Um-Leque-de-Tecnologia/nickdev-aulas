antes da palavra difícil · duas caixas

Duas maneiras de guardar coisas numa caixa

Caixa de sapatos

Não tem etiqueta dizendo o que pode entrar. Cabe um sapato, uma foto, um controle remoto quebrado — tudo junto, sem aviso.

Caixa de ovos

O formato já avisa o que cabe ali. Tenta enfiar outra coisa e não encaixa — o erro aparece na hora, antes de quebrar tudo.

Java é como a caixa de ovos: toda variável declara um tipo, e só aquele tipo cabe ali. O compilador confere isso antes do programa rodar — chama tipagem forte e estática.

tipos primitivos · os quatro que você vai usar o tempo todo

int, double, boolean, char

int

Número inteiro, sem casas decimais. 24, -7, 0.

double

Número com casas decimais. 3.14, -0.5.

boolean

Só existem dois valores: true ou false.

char

Um único caractere, entre aspas simples. 'N', '7'.

Existem outros (long, float, byte, short) — menos usados no dia a dia. Foco nesses quatro por hoje.

E o String, que a gente já usou?

Guarda texto: "Nicoly", "Orientação a Objetos". Só que, tecnicamente, String não é primitivo — é uma classe, ou seja, um objeto.

A gente entende essa diferença de verdade na aula 03, quando classe e objeto ganham nome e sobrenome. Por hoje, trate String como se fosse mais um tipo — ele se comporta parecido na hora de declarar.

sintaxe · tipo + nome + valor

Declarando variáveis

int idade = 24; double altura = 1.68; boolean estudando = true; char inicial = 'N'; String nome = "Nicoly";

Sempre nessa ordem: tipo nome = valor; — e sempre terminando com ;.

operadores aritméticos · + - * / %

Contas com números

int a = 7, b = 2; int soma = a + b; // 9 int divInt = a / b; // 3 (divisão inteira!) double divReal = a / 2.0; // 3.5 int resto = a % b; // 1 (resto da divisão)

Cuidado com o clássico: int / int sempre dá int, mesmo que o resultado "devesse" ter casas decimais. Pra divisão exata, pelo menos um dos dois precisa ser double.

operadores relacionais e lógicos · comparar e combinar

Perguntas que viram true/false

LógicosSignifica

Exemplo: idade >= 18 && temCarteira — só é true se as duas partes forem verdadeiras.

casting · trocando de tipo

Implícito × explícito

// implícito: Java faz sozinho, sem perigo de perda int idade = 24; double idadeDouble = idade; // 24.0 // explícito: você pede, com risco de perder informação double preco = 9.99; int precoInt = (int) preco; // 9 — trunca, não arredonda!

De um tipo "menor" pra um "maior" (int → double) o Java faz sozinho. Do "maior" pro "menor" (double → int) você precisa pedir explicitamente com (tipo) na frente — e avisar que aceita perder as casas decimais.

estruturas de decisão · if / else

Caminhos diferentes pra condições diferentes

int idade = 16; if (idade >= 18) { System.out.println("Maior de idade"); } else { System.out.println("Menor de idade"); }

Dá pra encadear com else if quantas vezes precisar — cada bloco só roda se a condição de cima for falsa.

estruturas de decisão · switch

Quando são muitos if/else na mesma variável

int diaDaSemana = 3; switch (diaDaSemana) { case 1: System.out.println("Domingo"); break; case 2: System.out.println("Segunda"); break; case 3: System.out.println("Terça"); break; default: System.out.println("Outro dia"); }

O break é o que impede o switch de "cair" pro próximo case de baixo. Esquecer ele é um dos erros mais comuns de quem está começando.

estruturas de repetição · for

Quando você já sabe quantas vezes

for (int i = 1; i <= 5; i++) { System.out.println("Volta número " + i); }

Três partes separadas por ;: onde começa (i = 1), até quando continua (i <= 5) e o que muda a cada volta (i++, que é i = i + 1).

estruturas de repetição · while e do-while

Quando você não sabe quantas vezes

while

int contador = 0; while (contador < 3) { System.out.println("oi"); contador++; }

do-while

int opcao; do { opcao = leitor.nextInt(); } while (opcao != 0);

A diferença: o do-while executa o bloco pelo menos uma vez antes de checar a condição — ótimo pra menus, que precisam aparecer antes de perguntar se o usuário quer sair.

// qual escolher?

for × while

Use for

Quando você sabe de antemão quantas repetições vai ter — percorrer um array, contar de 1 a N.

Use while

Quando a repetição depende de uma condição que só se sabe em tempo de execução — ler até o usuário digitar 0, por exemplo.

Não existe regra rígida — os dois conseguem fazer a mesma coisa. É sobre qual deixa a intenção do código mais clara pra quem lê.

arrays · uma variável, vários valores

Um armário com gavetas numeradas

Um array é um armário de tamanho fixo, com gavetas numeradas a partir do zero. Todas as gavetas guardam o mesmo tipo de coisa.

int[] notas = new int[5]; // armário com 5 gavetas, todas com 0 notas[0] = 8; // primeira gaveta notas[1] = 10; notas[4] = 6; // última gaveta (índice 4, não 5!)

Um array de tamanho 5 tem índices de 0 a 4. Tentar acessar notas[5] explode em ArrayIndexOutOfBoundsException.

arrays · percorrendo com for

Visitando gaveta por gaveta

int[] notas = {8, 10, 7, 9, 6}; for (int i = 0; i < notas.length; i++) { System.out.println("Nota " + i + ": " + notas[i]); }

notas.length dá o tamanho do array — sem parênteses, porque é um atributo, não um método. Ele evita o erro de passar do limite.

entrada de dados · Scanner

Perguntando pro usuário

Scanner leitor = new Scanner(System.in); System.out.print("Qual seu nome? "); String nome = leitor.nextLine(); System.out.print("Qual sua idade? "); int idade = leitor.nextInt();

Pegadinha clássica: depois de um nextInt() ou nextDouble(), um nextLine() logo em seguida costuma "pular" — sobrou uma quebra de linha no buffer. O guia da aula explica como contornar.

juntando tudo · mini programa

Média de uma turma

Scanner leitor = new Scanner(System.in); double[] notas = new double[3]; double soma = 0; for (int i = 0; i < notas.length; i++) { System.out.print("Nota " + (i + 1) + ": "); notas[i] = leitor.nextDouble(); soma += notas[i]; } double media = soma / notas.length; if (media >= 7) { System.out.println("Aprovado, média " + media); } else { System.out.println("Reprovado, média " + media); }

Scanner + array + for + if/else, tudo junto — exatamente a mistura que a Lista 1 vai pedir.
