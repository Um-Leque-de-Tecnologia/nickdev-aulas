Fundamentos da linguagem

Tipos primitivos, variáveis, operadores e casting; as estruturas de decisão e repetição; arrays; e como ler dados digitados pelo usuário com Scanner. É o vocabulário que você vai usar em toda classe Java daqui pra frente.

O dicionário desta aula

Hoje entram bastante palavras novas de uma vez. Volte aqui sempre que precisar — consultar dicionário não é trapaça, é o que todo mundo que programa faz o dia inteiro.

Tipos primitivos

São os tipos mais básicos que o Java já entende de fábrica, sem precisar de nenhuma classe. Os quatro que você vai usar quase sempre:

int

Número inteiro. 24, -7, 0.

double

Número com casas decimais. 3.14, -0.5.

boolean

Só true ou false.

char

Um único caractere, entre aspas simples. 'N'.

Existem outros tipos primitivos numéricos — long (inteiro bem maior que int), float (decimal com menos precisão que double), byte e short (inteiros bem pequenos). Eles existem por economia de memória em casos específicos; no dia a dia deste curso, int e double resolvem quase tudo.

E o String?

Você já usou String na aula 01 pra guardar texto. Ele não é um tipo primitivo — é uma classe, ou seja, tecnicamente já é um objeto. A gente entende essa diferença com profundidade na aula 03, quando "classe" e "objeto" ganham definição de verdade. Por enquanto, declare String como se fosse mais um tipo — a sintaxe é igual.

Por que isso importa (um pouquinho, desde já): tipos primitivos guardam o valor puro na variável. String e as outras classes guardam uma referência pra onde o valor mora na memória. Essa diferença fica bem mais clara depois da aula 03 — hoje só arquive a curiosidade.

Declarando variáveis

Toda variável em Java segue a mesma receita: tipo, depois nome, depois = e o valor, terminando com ;.

int idade = 24;
double altura = 1.68;
boolean estudando = true;
char inicial = 'N';
String nome = "Nicoly";

Dá pra declarar sem valor?

Sim — mas o Java obriga você a atribuir um valor antes de usar a variável. Declarar sem inicializar só reserva o nome e o tipo:

int pontuacao;     // declarada, ainda sem valor
pontuacao = 100;  // agora sim, pode usar

Nomeando variáveis

Convenção em Java: nomes de variáveis começam com letra minúscula e, se tiverem mais de uma palavra, usam camelCase — notaFinal, não nota_final nem NotaFinal. Isso é estilo, não regra da linguagem, mas seguir a convenção deixa seu código parecido com o de qualquer outro programa Java.

Operadores: aritméticos, relacionais e lógicos

Aritméticos — fazem contas

OperadorFaz
+ - *soma, subtração, multiplicação — sem surpresa
/divisão. Atenção: entre dois int, o resultado é sempre int (trunca as casas decimais)
%resto da divisão ("módulo"). 7 % 2 é 1
 
int a = 7, b = 2;

int divInt = a / b;        // 3 — divisão inteira
double divReal = a / 2.0;  // 3.5 — pelo menos um double
int resto = a % b;         // 1
O erro mais comum da aula: escrever media = soma / quantidade; com as três variáveis int e se perguntar por que a média "arredondou errado". Não arredondou — truncou, porque int / int descarta tudo depois da vírgula. A correção: declare pelo menos uma das variáveis como double, ou converta na hora da conta (veja casting, mais abaixo).

int idade = 20;

Casting

Casting é converter um valor de um tipo pra outro. Existem dois tipos:

Implícito (widening) — o Java faz sozinho

De um tipo "menor" pra um "maior" (ex.: int → double), não há risco de perder informação, então o Java converte automaticamente:

int idade = 24;
double idadeDouble = idade; // 24.0, sem você pedir nada

Explícito (narrowing) — você precisa pedir

De um tipo "maior" pra um "menor" (ex.: double → int) existe risco de perder informação — as casas decimais somem. Por isso o Java exige que você peça explicitamente, colocando o tipo entre parênteses na frente do valor:

double preco = 9.99;
int precoInt = (int) preco; // 9 — TRUNCA, não arredonda
Truncar ≠ arredondar. (int) 9.99 vira 9, não 10. O casting sempre descarta o que sobra, nunca arredonda pra cima. Se você precisa de arredondamento de verdade, existe Math.round(...) — fica de curiosidade pra pesquisar.

if / else

Escolhe um caminho de código com base numa condição que vale true ou false.

int idade = 16;

if (idade >= 18) {
  System.out.println("Maior de idade");
} else {
  System.out.println("Menor de idade");
}

Pra mais de duas opções, encadeia com else if:

if (nota >= 7) {
  System.out.println("Aprovado");
} else if (nota >= 5) {
  System.out.println("Recuperação");
} else {
  System.out.println("Reprovado");
}

Cada bloco else if só é conferido se todos os anteriores foram falsos — e o Java para no primeiro que der true.

switch

Quando você tem muitos else if comparando a mesma variável a valores diferentes, o switch costuma ficar mais legível:

int diaDaSemana = 3;

switch (diaDaSemana) {
  case 1:
    System.out.println("Domingo");
    break;
  case 2:
    System.out.println("Segunda");
    break;
  case 3:
    System.out.println("Terça");
    break;
  default:
    System.out.println("Outro dia");
}
O erro clássico: esquecer o break. Sem ele, a execução "cai" pro case seguinte mesmo depois de já ter achado o valor certo — chamado de fall-through. É raro ser o que você quer; acostume a mão a sempre fechar cada case com break.

default é opcional, e roda quando nenhum case bate com o valor — funciona como o else final de uma cadeia de if.

for

Use quando você já sabe (ou consegue calcular) quantas vezes quer repetir.

for (int i = 1; i <= 5; i++) {
  System.out.println("Volta número " + i);
}

O for tem três partes, separadas por ;:

  • Inicialização (int i = 1) — roda uma vez só, antes de tudo
  • Condição (i <= 5) — conferida antes de cada volta; enquanto for true, o laço continua
  • Incremento (i++) — roda no fim de cada volta. i++ é atalho pra i = i + 1

while e do-while

while — confere antes de executar

int contador = 0;

while (contador < 3) {
  System.out.println("oi");
  contador++;
}

Se a condição já começar falsa, o bloco nunca executa nenhuma vez.

do-while — executa antes de conferir

int opcao;

do {
  System.out.print("Digite 0 para sair: ");
  opcao = leitor.nextInt();
} while (opcao != 0);

A diferença: o do-while roda o bloco pelo menos uma vez, e só depois confere a condição. É a estrutura clássica de menu: você quer mostrar as opções antes de perguntar se o usuário quer parar.

Cuidado com laço infinito. Se nada dentro do bloco mudar a condição (esquecer o contador++, por exemplo), o laço nunca termina. Todo laço precisa de um caminho garantido pra condição virar falsa.

Arrays

Um array é uma variável que guarda vários valores do mesmo tipo, num bloco de tamanho fixo, acessados por um número chamado índice — que começa em 0.

Declarando e preenchendo

int[] notas = new int[5]; // 5 posições, todas com 0 por padrão

notas[0] = 8;
notas[1] = 10;
notas[4] = 6; // última posição válida: índice 4, não 5

Ou, se você já sabe os valores de antemão, dá pra declarar tudo de uma vez:

int[] notas = {8, 10, 7, 9, 6};
Por que o índice começa em 0? O índice não é "a posição", é o quanto você anda a partir do início. A primeira posição está a 0 passos do começo. Um array de tamanho 5 tem índices 0, 1, 2, 3, 4 — o último é sempre tamanho - 1.

Percorrendo com for

for (int i = 0; i < notas.length; i++) {
  System.out.println("Nota " + i + ": " + notas[i]);
}

notas.length devolve o tamanho do array — sem parênteses, porque é um atributo, não um método (diferente de String, que usa .length() com parênteses — sim, é inconsistente, e sim, todo mundo confunde isso no começo).

ArrayIndexOutOfBoundsException. É o erro que aparece quando você tenta acessar um índice que não existe — notas[5] num array de tamanho 5, por exemplo. Usar notas.length na condição do for (como acima) evita esse erro na prática.

Scanner

Scanner é a ferramenta padrão do Java pra ler o que o usuário digita no terminal. Ele fica na biblioteca java.util, então o arquivo precisa começar com um import:

import java.util.Scanner;

public class Programa {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Qual seu nome? ");
    String nome = leitor.nextLine();

    System.out.print("Qual sua idade? ");
    int idade = leitor.nextInt();
  }
}

Os métodos mais usados

MétodoLê
nextLine()uma linha inteira de texto (pode ter espaços)
nextInt()um número inteiro
nextDouble()um número com casas decimais
nextBoolean()true ou false
A pegadinha do nextLine() depois de nextInt(). Quando você digita um número e aperta Enter, o nextInt() lê só o número — a quebra de linha do Enter fica "esperando" no buffer. Se o próximo comando for nextLine(), ele lê essa quebra de linha sobrando (uma linha vazia) em vez de esperar você digitar algo novo. A correção mais simples: adicione um leitor.nextLine(); extra logo depois do nextInt()/nextDouble(), só pra "limpar" essa sobra.
int idade = leitor.nextInt();
leitor.nextLine();  // limpa a quebra de linha que sobrou

System.out.print("Qual seu nome completo? ");
String nome = leitor.nextLine();  // agora funciona certo
