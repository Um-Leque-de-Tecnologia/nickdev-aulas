Lista 1 · Aula 02

Fundamentos da linguagem 🔁

Seis exercícios curtos, cada um focado num pedaço do que vimos hoje. Resolva cada um numa classe Java separada, compile e rode pelo terminal — igual você já fez na Lista 0 (o desafio da aula 01).

🎯

O objetivo

Fixar, na mão, o vocabulário que vai aparecer em praticamente toda classe Java que você escrever daqui pra frente:

  1. Tipos primitivos, variáveis e leitura de dados com Scanner
  2. Operadores aritméticos, relacionais e lógicos
  3. Estruturas de decisão: if/else e switch
  4. Estruturas de repetição: for, while e do-while
  5. Arrays, percorridos com for
📖

Travou numa palavra?

Casting, índice, laço, array — se alguma dessas aparecer aqui e você não lembrar o que é, o guia da aula tem um dicionário com todas elas em português simples.

Os 6 exercícios
01

Classificador de idade

tipos primitivos · Scanner · if/else

Crie a classe ClassificadorIdade. Leia a idade da pessoa (um int) com Scanner e imprima a faixa etária:

  • 0 a 11 → "Criança"
  • 12 a 17 → "Adolescente"
  • 18 a 59 → "Adulto"
  • 60 ou mais → "Idoso"
$ java ClassificadorIdade Digite a idade: 15 Adolescente

Dica: ordene as comparações da mais específica pra mais geral, ou use else if em cascata — sem precisar checar intervalo duplo (tipo idade >= 12 && idade <= 17 já resolve, mas dentro de uma cadeia de else if nem precisa do limite de baixo).

02

Calculadora simples

operadores aritméticos · Scanner · switch

Crie a classe CalculadoraSimples. Leia dois números (double) e um caractere representando a operação (+, -, * ou /). Use um switch pra escolher a operação e imprima o resultado.

$ java CalculadoraSimples Primeiro número: 10 Segundo número: 4 Operação (+, -, *, /): / Resultado: 2.5

Cuidado: se os dois números forem double desde a declaração, a divisão já sai com casas decimais — não precisa de casting aqui.

03

Média e situação

operadores relacionais · if/else

Crie a classe MediaSituacao. Leia três notas (double), calcule a média aritmética e imprima a situação:

  • Média ≥ 7 → "Aprovado"
  • Média ≥ 5 e < 7 → "Recuperação"
  • Média < 5 → "Reprovado"
$ java MediaSituacao Nota 1: 8 Nota 2: 6 Nota 3: 7 Média: 7.0 Situação: Aprovado

Revisão do slide de operadores: se as três notas e a soma forem double, dividir por 3 (um int) funciona sem problema — o Java promove o 3 pra double automaticamente porque um dos lados já é double.

04

Tabuada

for · Scanner

Crie a classe Tabuada. Leia um número inteiro e imprima a tabuada dele, de 1 a 10, usando um for.

$ java Tabuada Digite um número: 7 7 x 1 = 7 7 x 2 = 14 7 x 3 = 21 ... 7 x 10 = 70
05

Pares em um array

arrays · for

Crie a classe ParesNoArray. Leia um número N (tamanho do array) e depois N números inteiros, guardando tudo num array. Depois, percorra o array com um for e imprima apenas os números pares (use % pra descobrir).

$ java ParesNoArray Quantos números? 5 Número 1: 3 Número 2: 8 Número 3: 11 Número 4: 4 Número 5: 7 Pares: 8 4

Dica: um número é par quando numero % 2 == 0.

06

Contador com while

while ou do-while · Scanner

Crie a classe ContadorAteZero. Peça números ao usuário, um de cada vez, até ele digitar 0. No fim, imprima quantos números (sem contar o 0) foram digitados.

$ java ContadorAteZero Digite um número (0 para parar): 5 Digite um número (0 para parar): 12 Digite um número (0 para parar): 3 Digite um número (0 para parar): 0 Você digitou 3 números.

while ou do-while? Os dois resolvem — pense em qual deixa a leitura mais natural. O guia da aula compara os dois no slide 15.

Requisitos mínimos
  • Seis classes, uma por exercício, cada uma com seu próprio main
  • Cada exercício usa pelo menos os tópicos indicados no cabeçalho dele
  • Todas as entradas vêm de Scanner — nada de valores fixos no código
  • Compiladas com javac e executadas com java pelo terminal
  • Publicadas no mesmo repositório GitHub da Lista 0 (aula 01), numa pasta lista-1
Desafios extras (pra quem quer brilhar ✨)
  • No exercício 2 (calculadora), trate divisão por zero antes de dividir e avise o usuário em vez de deixar o programa quebrar
  • No exercício 5 (array), some os pares encontrados e imprima também a soma
  • Reescreva o exercício 4 (tabuada) usando while em vez de for
  • Adicione um README.md na pasta lista-1 explicando o que cada exercício faz
