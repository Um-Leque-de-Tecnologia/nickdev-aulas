✅ 1 · Classificador de idade

ClassificadorIdade.java

Uma cadeia de else if, da faixa mais específica pra mais geral.

import java.util.Scanner;

public class ClassificadorIdade {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Digite a idade: ");
    int idade = leitor.nextInt();

    if (idade <= 11) {
      System.out.println("Criança");
    } else if (idade <= 17) {
      System.out.println("Adolescente");
    } else if (idade <= 59) {
      System.out.println("Adulto");
    } else {
      System.out.println("Idoso");
    }
  }
}

Repare que cada else if só precisa checar o limite de cima — se chegou até ali, é porque o limite de baixo já foi descartado pelo bloco anterior.

✅ 2 · Calculadora simples

CalculadoraSimples.java ★

Lê a operação como um único caractere (char) e usa switch pra escolher a conta.

import java.util.Scanner;

public class CalculadoraSimples {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Primeiro número: ");
    double a = leitor.nextDouble();

    System.out.print("Segundo número: ");
    double b = leitor.nextDouble();

    System.out.print("Operação (+, -, *, /): ");
    char operacao = leitor.next().charAt(0);

    double resultado = 0;
    switch (operacao) {
      case '+': resultado = a + b; break;
      case '-': resultado = a - b; break;
      case '*': resultado = a * b; break;
      case '/': resultado = a / b; break;
      default: System.out.println("Operação inválida"); return;
    }
    System.out.println("Resultado: " + resultado);
  }
}

leitor.next() lê uma "palavra" (sem espaços) como String; .charAt(0) pega só o primeiro caractere dela, virando um char. O default com return encerra o programa cedo se a operação digitada não for uma das quatro esperadas.

✅ 3 · Média e situação

MediaSituacao.java

import java.util.Scanner;

public class MediaSituacao {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Nota 1: ");
    double nota1 = leitor.nextDouble();
    System.out.print("Nota 2: ");
    double nota2 = leitor.nextDouble();
    System.out.print("Nota 3: ");
    double nota3 = leitor.nextDouble();

    double media = (nota1 + nota2 + nota3) / 3;
    System.out.println("Média: " + media);

    if (media >= 7) {
      System.out.println("Situação: Aprovado");
    } else if (media >= 5) {
      System.out.println("Situação: Recuperação");
    } else {
      System.out.println("Situação: Reprovado");
    }
  }
}

As três notas já são double, então (nota1 + nota2 + nota3) / 3 não sofre o problema da divisão inteira — mesmo o 3 sendo um número "sem vírgula" no código, o Java promove ele pra double na hora da conta.

✅ 4 · Tabuada

Tabuada.java

import java.util.Scanner;

public class Tabuada {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Digite um número: ");
    int numero = leitor.nextInt();

    for (int i = 1; i <= 10; i++) {
      System.out.println(numero + " x " + i + " = " + (numero * i));
    }
  }
}

Os parênteses em (numero * i) não são opcionais aqui: sem eles, o Java concatenaria " = " com numero primeiro (texto + número vira texto) e só depois tentaria multiplicar texto por i — erro de compilação. Os parênteses garantem que a multiplicação aconteça antes da concatenação.

✅ 5 · Pares em um array

ParesNoArray.java ★

import java.util.Scanner;

public class ParesNoArray {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);

    System.out.print("Quantos números? ");
    int quantidade = leitor.nextInt();

    int[] numeros = new int[quantidade];
    for (int i = 0; i < numeros.length; i++) {
      System.out.print("Número " + (i + 1) + ": ");
      numeros[i] = leitor.nextInt();
    }

    System.out.print("Pares: ");
    for (int i = 0; i < numeros.length; i++) {
      if (numeros[i] % 2 == 0) {
        System.out.print(numeros[i] + " ");
      }
    }
  }
}

Dois laços for separados: o primeiro preenche o array (lendo do usuário), o segundo percorre pra filtrar os pares. É comum precisar de um laço pra cada responsabilidade — tentar fazer tudo num só geralmente complica mais do que ajuda.

✅ 6 · Contador com while

ContadorAteZero.java

import java.util.Scanner;

public class ContadorAteZero {
  public static void main(String[] args) {
    Scanner leitor = new Scanner(System.in);
    int contador = 0;
    int numero;

    do {
      System.out.print("Digite um número (0 para parar): ");
      numero = leitor.nextInt();
      if (numero != 0) {
        contador++;
      }
    } while (numero != 0);

    System.out.println("Você digitou " + contador + " números.");
  }
}

do-while encaixa perfeitamente aqui: você precisa pedir o primeiro número antes de ter qualquer coisa pra comparar. O if dentro do laço evita contar o próprio 0 que encerrou a repetição.

⚠️ Erros comuns

Os 4 erros que mais aparecem

error: incompatible types: possible lossy conversion from double to int

Você tentou guardar um double numa variável int sem casting explícito. Ou converte com (int), ou muda o tipo da variável pra double.

Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 5 out of bounds for length 5

Tentou acessar uma posição do array que não existe. Lembre: um array de tamanho 5 vai do índice 0 ao 4. Usar array.length na condição do for evita esse erro.

Exception in thread "main" java.util.InputMismatchException

O Scanner esperava um tipo (ex.: nextInt()) e o usuário digitou outra coisa (uma letra, por exemplo). Fora do escopo desta lista tratar isso — só fique de olho na hora de testar.

// programa "trava" (loop infinito)

Em algum while/do-while, a condição nunca vira falsa — geralmente porque esqueceram de atualizar a variável que ela depende (tipo esquecer o contador++). Todo laço precisa de um caminho garantido pra terminar.
