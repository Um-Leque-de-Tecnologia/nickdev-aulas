API no ar ✅

O desafio resolvido com o tema "livros": record, @Service com cinco itens, @RestController com injeção por construtor e três rotas GET — com a saída real do terminal.

As três classes
LivroService.java
@Service
public class LivroService {

  private final List<Livro> acervo = List.of(
    new Livro("Duna", "Frank Herbert", 1965, "Ficção", 9.2),
    new Livro("Neuromancer", "W. Gibson", 1984, "Ficção", 8.7),
    new Livro("Vidas Secas", "G. Ramos", 1938, "Drama", 9.0),
    new Livro("Torto Arado", "I. V. Junior", 2019, "Drama", 9.5),
    new Livro("O Cortiço", "A. Azevedo", 1890, "Realismo", 8.4)
  );

  public List<Livro> listar() { return acervo; }

  public Livro destaque() {
    return acervo.stream()
      .max(Comparator.comparingDouble(Livro::nota))
      .orElseThrow();
  }

  public List<Livro> porGenero(String g) {
    return acervo.stream()
      .filter(l -> l.genero().equalsIgnoreCase(g))
      .toList();
  }
}
LivroController.java
@RestController
@RequestMapping("/livros")
public class LivroController {

  private final LivroService service;

  // sem new, sem @Autowired
  public LivroController(LivroService service) {
    this.service = service;
  }

  @GetMapping
  public List<Livro> listar() {
    return service.listar();
  }

  @GetMapping("/destaque")
  public Livro destaque() {
    return service.destaque();
  }

  @GetMapping("/genero/{genero}")
  public List<Livro> porGenero(
      @PathVariable String genero) {
    return service.porGenero(genero);
  }
}

Por que essa solução funciona

Injeção por construtor

Nenhum new LivroService(). O Spring viu o construtor pedindo o tipo, achou o bean e entregou — e o campo pôde ser final.

Regra no service

Os três stream() vivem no service. O controller só recebe a requisição e repassa: ele não sabe filtrar, só sabe falar HTTP.

JSON de graça

O record volta como objeto e o Jackson serializa sozinho, com Content-Type: application/json correto.

Checklist batido
  • Spring Boot 4.1 com Java 21, subindo em pouco mais de 1 segundo
  • record Livro com 5 campos (mais que o mínimo de 4)
  • @Service com 5 livros no acervo
  • @RestController com injeção por construtor, sem @Autowired
  • 3 rotas GET, a terceira com @PathVariable e filtro
  • A filtragem acontece no service, via Stream API
  • Tudo dentro do pacote da classe main
