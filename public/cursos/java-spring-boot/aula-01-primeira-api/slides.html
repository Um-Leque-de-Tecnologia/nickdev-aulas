revisão · exceções

Exceções: avisar que deu errado

// exceção própria, herdando de RuntimeException public class MidiaNaoEncontradaException extends RuntimeException { public MidiaNaoEncontradaException(String titulo) { super("Mídia não encontrada: " + titulo); } } // lançando if (achou == null) throw new MidiaNaoEncontradaException(titulo);

checked × unchecked

RuntimeException não obriga try/catch. Exception obriga.

No Spring

Você lança a exceção e um tratador global transforma ela em resposta HTTP 404. Aula 03.

Regra que vale pra hoje: exceção é pra o que foge do esperado, não pra controlar fluxo normal. "Lista vazia" não é exceção; "id que não existe" é.

List, Map, Set — e o <tipo>

// generics: o <Midia> é o que evita cast e erro em tempo de execução List<Midia> acervo = List.of(duna, cidadeDeDeus); // List.of devolve lista IMUTÁVEL — add() lança exceção

O <T> não é enfeite: sem ele, tudo vira Object e o erro só aparece quando o programa roda. Com ele, o compilador pega antes.

revisão · lambdas e streams

A Stream API que você vai usar hoje

// filtrar por gênero acervo.stream() .filter(m -> m.genero().equalsIgnoreCase(genero)) .toList(); // o de maior nota acervo.stream() .max(Comparator.comparingDouble(Midia::nota)) .orElseThrow(); // agrupar por gênero acervo.stream() .collect(Collectors.groupingBy(Midia::genero));

No desafio de hoje, a rota com filtro é exatamente o primeiro exemplo — e ela mora no service, não no controller.

revisão · Optional e record

Duas peças que o Spring adora

Optional — "pode não ter"
Optional<Midia> achada = acervo.stream() .filter(m -> m.titulo().equals(t)) .findFirst(); achada.orElseThrow(() -> new MidiaNaoEncontradaException(t));

O tipo já avisa que pode vir vazio. Menos null, menos NullPointerException.

record — transportar dados
public record Midia( String titulo, int ano, String genero) {} // já vem com construtor, getters, // equals, hashCode e toString

É o que a gente vai devolver nas rotas — e o Jackson converte pra JSON sozinho.

O Optional vai aparecer de novo na aula 04: findById() do Spring Data devolve exatamente isso.

O new espalhado

inversão de controle · o conceito do dia

E se alguém entregasse pronto?

🌱 com injeção de dependência
@Service class MidiaServico { private final MidiaRepositorio repo; // o Spring entrega o repositório pronto MidiaServico(MidiaRepositorio repo) { this.repo = repo; } }

A classe só pede

"eu preciso de um MidiaRepositorio". Quem escolhe qual é o Spring.

Testável

No teste, você passa um repositório falso pelo construtor. Sem mágica.

Inversão de controle: o controle de criar as dependências sai da sua classe e vai pro framework. Injeção de dependência é como isso acontece na prática.

spring boot · o que ele é, afinal

Spring, Boot e o resto

NomeO que é
Spring FrameworkO contêiner de injeção de dependência e um monte de módulos (web, dados, segurança). Existe desde 2003.
Spring BootUma camada por cima que configura o Spring sozinha e embute um servidor. É por isso que dá pra rodar com um clique.
StartersPacotes de dependências que já vêm combinadas e testadas: spring-boot-starter-web traz tudo pra fazer API.

Sem o Boot, subir uma aplicação Spring pedia dezenas de linhas de XML e um servidor instalado à parte. Ele existe pra você não fazer isso.

o ponto de entrada · reconhece o main?

Ainda é um main comum

📄 CatalogoApplication.java
@SpringBootApplication public class CatalogoApplication { public static void main(String[] args) { SpringApplication.run(CatalogoApplication.class, args); } }

O mesmo public static void main da aula 01 de OO. A diferença é o que ele faz: sobe o contêiner do Spring e um servidor web embutido.

@SpringBootApplication · três em uma

O que essa anotação liga

@Configuration

marca a classe como fonte de configuração.

@EnableAutoConfiguration

configura sozinho o que achar no classpath. Achou Spring Web? Sobe um servidor.

@ComponentScan

varre o pacote atrás das suas classes anotadas — e é assim que ele te acha.

⚠️ O ComponentScan varre a partir do pacote da classe main. Classe criada fora dele não é encontrada — esse é o erro nº 1 de quem começa.

json de graça · devolvendo objeto

Devolva um objeto, receba JSON

📄 o record e a rota
public record Midia( String titulo, int ano, String genero) {} @GetMapping("/midias/destaque") public Midia destaque() { return new Midia("Duna", 2021, "Ficção"); }
📦 o que chega no navegador
{ "titulo": "Duna", "ano": 2021, "genero": "Ficção" }

Ninguém escreveu conversão pra JSON. O Spring usa a biblioteca Jackson por baixo e serializa sozinho. record é Java puro — você já viu na aula de OO.

bean · a palavra que você vai ouvir o tempo todo

O que é um bean

Um bean é só um objeto que o Spring criou e guarda pra você. Quando ele sobe, varre seu código, encontra as classes anotadas e cria uma instância de cada.

AnotaçãoPapel na camada
@RestControllerrecebe requisição HTTP e devolve resposta
@Serviceregra de negócio
@Repositoryacesso a dados
@Componentqualquer outro bean

Tecnicamente as quatro fazem a mesma coisa: viram bean. A diferença é a intenção — quem lê o código sabe na hora qual é o papel daquela classe.

live code · duas camadas conversando

Injetando de verdade

📄 service/MidiaService.java
@Service public class MidiaService { public List<Midia> listar() { return List.of( new Midia("Duna", 2021, "Ficção"), new Midia("Cidade de Deus", 2002, "Drama") ); } }
📄 controller/MidiaController.java
@RestController @RequestMapping("/midias") public class MidiaController { private final MidiaService service; // injeção por construtor public MidiaController(MidiaService service) { this.service = service; } @GetMapping public List<Midia> listar() { return service.listar(); } }

Repare: nenhum new MidiaService(). O Spring viu o construtor pedindo um MidiaService, achou o bean e entregou.

o jeito certo · construtor, não @Autowired no campo

Injete pelo construtor

❌ no campo

@Autowired private MidiaService service;

Não dá pra marcar final, e num teste você não consegue passar um dublê sem refletir.

✅ no construtor

private final MidiaService service; public MidiaController(MidiaService s) { this.service = s; }

Fica final, o objeto nasce completo, e o teste é um new comum.

Com um único construtor, o @Autowired é opcional — pode omitir. É o padrão recomendado pela própria equipe do Spring.

quando der errado · e vai dar

Os quatro erros de estreia

O que apareceO que é
Whitelabel Error Page 404a rota não existe. Confira o caminho e se a classe tem @RestController.
Port 8080 was already in usetem outra aplicação rodando. Pare a anterior ou mude a porta.
No qualifying bean of type...o Spring não achou o bean. A classe está fora do pacote da main ou faltou a anotação.
página em branco com o texto da rotavocê usou @Controller em vez de @RestController.

Leia a primeira linha do erro, não a pilha inteira. O Spring costuma dizer exatamente o que falta — inclusive sugerindo a correção.
