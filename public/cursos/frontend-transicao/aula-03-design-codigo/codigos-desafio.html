🔥 Parte 1 · Card de perfil (aquecimento)

HTML — a estrutura (semântica!)

Cada tag diz o que a coisa é: título → <h1>/<h2>, texto → <p>, o card → <article>. <div> só pra agrupar/layout.

<article class="card">
  <div class="banner"></div>

  <div class="topo">
    <div class="avatar">N</div>
    <h1 class="nome">Nicoly Almeida</h1>       <!-- nome = título → h1 -->
    <p class="handle">@nickdeve</p>            <!-- texto → p -->
    <p class="bio">Desenvolvedora & professora. 💜</p>
  </div>

  <!-- cada stat: número em destaque (strong) + rótulo (span) -->
  <div class="stats">
    <div><strong class="num">32</strong><span class="lbl">Projetos</span></div>
    <div><strong class="num">1.2k</strong><span class="lbl">Seguidores</span></div>
    <div><strong class="num">890</strong><span class="lbl">Curtidas</span></div>
  </div>

  <button class="btn-seguir" id="seguir">Seguir</button>

  <h2 class="galeria-titulo">Meus projetos</h2>  <!-- título de seção → h2 -->
  <div class="galeria">
    <div class="g1"></div><div class="g2"></div>
    <div class="g3"></div><div class="g4"></div>
  </div>

  <div class="tags">
    <span>#dev</span> <span>#design</span> <span>#café</span>
  </div>
</article>
Por que não tudo <div>? 💡 Isso se chama HTML semântico. Tags que dizem o significado (título, parágrafo, artigo) ajudam leitores de tela, o Google e você mesma a entender o código. <div> não tem significado — use só pra agrupar e dar layout.

JS — o botão Seguir

Uma única interação: alterna a classe e o texto ao clicar.

const botao = document.querySelector("#seguir");

botao.addEventListener("click", () => {
  botao.classList.toggle("seguindo");
  botao.textContent = botao.classList.contains("seguindo")
    ? "Seguindo ✓"
    : "Seguir";
});

2 · O componente ★

Uma função que recebe 1 projeto e devolve 1 card. É isto que a gente reaproveita — a estrutura, não só o estilo. Um componente = função que devolve HTML.

function criarCard(projeto) {
  const col = document.createElement("div");
  col.className = "col";   // coluna do grid do Bootstrap
  col.innerHTML = `
    <div class="card h-100 border-0 shadow-sm">
      <div class="cover" style="background:${projeto.cor}"></div>
      <div class="card-body">
        <span class="badge rounded-pill tag-badge">${projeto.categoria}</span>
        <h3 class="card-title h6 mt-2 mb-3">${projeto.titulo}</h3>
        <button class="curtir btn btn-sm btn-outline-secondary rounded-pill">
          <span class="coracao">🤍</span> <span class="n">${projeto.curtidas}</span>
        </button>
      </div>
    </div>`;

  // a interação do curtir vive DENTRO do componente
  const btn = col.querySelector(".curtir");
  let curtido = false, total = projeto.curtidas;
  btn.addEventListener("click", () => {
    curtido = !curtido;
    total += curtido ? 1 : -1;
    col.querySelector(".n").textContent = total;
    col.querySelector(".coracao").textContent = curtido ? "❤️" : "🤍";
    btn.classList.toggle("liked", curtido);
  });

  return col;
}
Ponte pro React: quando você vir function Card() {} no React, é a mesma ideia — uma função que devolve um pedaço de tela. Hoje vocês fizeram no braço; o React automatiza isso.

3 · Render + filtro

Um forEach reaproveita o componente pra cada item. O filtro só muda a lista.

const grid = document.querySelector("#grid");
let filtroAtual = "Todos";

function render(lista) {
  grid.innerHTML = "";
  lista.forEach(p => grid.appendChild(criarCard(p)));
}

function aplicarFiltro() {
  const lista = (filtroAtual === "Todos")
    ? projetos
    : projetos.filter(p => p.categoria === filtroAtual);
  render(lista);
}

document.querySelectorAll(".filtro").forEach(botao => {
  botao.addEventListener("click", () => {
    document.querySelectorAll(".filtro").forEach(b => b.classList.remove("active"));
    botao.classList.add("active");
    filtroAtual = botao.dataset.cat;
    aplicarFiltro();
  });
});
