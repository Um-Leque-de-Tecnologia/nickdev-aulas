🎨 Parte 2 · CSS — o estilo

Tokens (:root)

As cores e medidas da ficha técnica, guardadas em variáveis.

:root {
  --rosa: #F24487;
  --roxo: #7B4FD0;
  --gradiente: linear-gradient(120deg, #F24487, #7B4FD0);
  --fundo: #EEF0F6;
  --card: #FFFFFF;
  --texto: #1B1830;
  --texto-suave: #6B6580;
  --raio: 22px;
  --sombra: 0 24px 60px -24px rgba(74,40,120,.45);
}

Base + centralizar (Flexbox)

O reset e o body que joga o card pro centro da tela.

* { margin: 0; padding: 0; box-sizing: border-box; }

body {
  font-family: 'Poppins', sans-serif;
  background: var(--fundo);
  color: var(--texto);
  min-height: 100vh;
  display: flex;
  align-items: center;
  justify-content: center;
}

Card + banner

overflow: hidden faz o banner respeitar os cantos arredondados.

.card {
  width: 100%;
  max-width: 380px;
  background: var(--card);
  border-radius: var(--raio);
  box-shadow: var(--sombra);
  overflow: hidden;
}
.banner {
  height: 96px;
  background: var(--gradiente);
}

Topo (avatar sobre o banner)

O truque: margin-top negativo puxa a foto pra cima do banner.

.topo { text-align: center; margin-top: -46px; padding: 0 26px; }

.avatar {
  width: 92px;
  height: 92px;
  border-radius: 50%;
  border: 4px solid var(--card);
  object-fit: cover;
}
.nome { font-size: 22px; font-weight: 600; margin-top: 12px; }
.handle { color: var(--texto-suave); font-size: 14px; }

Stats — Grid de 3 colunas

repeat(3, 1fr) = 3 colunas de tamanho igual.

.stats {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  text-align: center;
  margin: 22px 26px;
  padding: 16px 0;
  border-top: 1px solid var(--linha);
  border-bottom: 1px solid var(--linha);
}
.stats .num { font-weight: 600; font-size: 18px; }
.stats .lbl { color: var(--texto-suave); font-size: 12px; }

Botão Seguir

Gradiente, pílula (border-radius: 100px) e um estado alternativo .seguindo.

.btn-seguir {
  width: 100%;
  color: #fff;
  background: var(--gradiente);
  border: 0;
  padding: 13px;
  border-radius: 100px;
  cursor: pointer;
  transition: transform .15s, box-shadow .25s;
}
.btn-seguir:hover { transform: translateY(-2px); }

/* depois de clicar: vira contornado */
.btn-seguir.seguindo {
  background: #fff;
  color: var(--roxo);
  border: 1px solid var(--roxo);
}

Galeria — Grid 2×2

Duas colunas; cada quadradinho com uma cor.

.galeria {

Tags — Flexbox que quebra linha

flex-wrap: wrap deixa as pílulas pularem pra linha de baixo.

.tags {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
  padding: 18px 26px 28px;

.tags span {
  font-size: 12px;
  color: var(--roxo);
  background: #F3EEFC;

⚡ Parte 3 · JavaScript — a interação

Botão Seguir ↔ Seguindo

Um evento de clique que liga/desliga a classe .seguindo e troca o texto.

const botao = document.querySelector("#seguir");

botao.addEventListener("click", () => {
  botao.classList.toggle("seguindo");

  if (botao.classList.contains("seguindo")) {
    botao.textContent = "Seguindo ✓";
  } else {
    botao.textContent = "Seguir";
  }
});
