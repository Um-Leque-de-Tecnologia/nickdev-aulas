Desafio · Aula 03

Do design ao código 🎨

Todo dev recebe um design pronto e precisa transformá-lo em página de verdade. Hoje é sua vez: recrie a tela de perfil abaixo com HTML e CSS, o mais fiel possível ao design. É assim que se trabalha no mundo real. 🚀

🎯

O objetivo

Reproduzir a tela usando design tokens (variáveis), Flexbox e Grid. Chegar o mais perto possível do design — isso se chama fidelidade.

O design (seu alvo)

Passo a passo
01

Leia o design antes de codar

Olhe a tela e liste os blocos: banner, foto, nome, bio, stats, botão, galeria, tags. Repare no que se repete e no espaçamento entre as coisas.

Dica de dev: desenhe caixas por cima do design (na imaginação ou no papel). Cada caixa vira uma <div>.

02

Comece pelos tokens

Coloque as cores e medidas da ficha técnica em variáveis no :root. Depois é só usar var(--rosa) em vez de repetir o hex.

:root {
  --rosa: #F24487;
  --roxo: #7B4FD0;
  --gradiente: linear-gradient(120deg, #F24487, #7B4FD0);
  --card: #fff;
  --raio: 22px;
}
03

Centralize o card (Flexbox)

O card fica no meio da tela. Flexbox no body resolve:

body {
  min-height: 100vh;
  display: flex;
  align-items: center;     /* vertical */
  justify-content: center; /* horizontal */
}
04

Stats e galeria (Grid)

Onde há colunas iguais, use Grid. Stats = 3 colunas; galeria = 2 colunas.

.stats {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 iguais */
}
.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr;        /* 2 iguais */
  gap: 10px;
}
05

Capriche nos detalhes

É aqui que a fidelidade acontece: cantos arredondados (border-radius), sombra (box-shadow), o avatar redondo puxado pra cima do banner (margin-top negativo), e o botão com gradiente.

Compare lado a lado: deixe o design aberto do lado do seu código e vá ajustando até ficar igual.

06

Uma interação + publicar

Use o JavaScript da aula 2 pro botão Seguir virar Seguindo ✓ ao clicar. Depois, publique na Vercel. 🌍

const botao = document.querySelector("#seguir");
botao.addEventListener("click", () => {
  botao.classList.toggle("seguindo");
});
Requisitos mínimos
  • As cores e a fonte batendo com a ficha técnica
  • Design tokens em variáveis no :root
  • O card centralizado na tela com Flexbox
  • Stats e galeria feitos com Grid
  • Avatar redondo, cantos arredondados e sombra no card
  • Botão Seguir que muda de estado ao clicar
  • Publicado na Vercel com link funcionando
Desafios extras (pra quem quer brilhar ✨)
  • Deixar responsivo pra ficar bonito no celular
  • Um :hover com leve elevação no card e nos quadradinhos da galeria
  • Trocar a foto de iniciais por uma imagem de verdade (<img>)
  • Animar o número de seguidores subindo (pesquise transition / JS)
  • Um segundo tema de cores só trocando os tokens do :root
