o olho de dev · antes de codar

Leia o design primeiro

  • Blocos — quais são as caixas grandes? (viram div)
  • Repetição — o que se repete? (vira um componente)
  • Alinhamento — centralizado? em colunas?
  • Espaçamento — quanto de respiro entre as coisas?
  • Hierarquia — o que é título? o que é secundário?

design tokens · a paleta em variáveis

Cores e medidas viram variáveis

No design

o designer definiu rosa #F24487, roxo #7B4FD0, cantos de 22px...

No CSS

:root {
  --rosa: #F24487;
  --raio: 22px;
}

Usa com var(--rosa). Pra trocar o tema todo, muda uma variável só.

espaçamento · o segredo do "profissional"

padding · margin · gap

padding

espaço dentro da caixa.

margin

espaço fora da caixa.

gap

espaço entre itens de flex/grid.

Dica de ouro: use múltiplos de 8 (8 · 16 · 24 · 32). É o "grid de 8pt" — alinha tudo sem esforço.

flexbox · alinhar numa direção
{ display:flex }

Flexbox organiza itens num eixo (linha ou coluna). É o jeito mais fácil de centralizar e distribuir.

.barra {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 12px;
}

grid · colunas e linhas de verdade
{ display:grid }

Quando precisa de colunas (galeria, cards lado a lado), Grid é o ideal.

1fr = uma fração do espaço. repeat(3, 1fr) = 3 colunas iguais.

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Flexbox ou Grid?

Flexbox

Uma direção: uma linha ou uma coluna. Ex.: uma barra de navegação, botões em fila.

Grid

Duas direções: linhas e colunas, uma grade. Ex.: galeria de fotos, cards em grade.

Na dúvida: é uma fileira? Flex. É uma grade? Grid. E pode usar os dois juntos!

componentes · pensar em blocos

O que se repete vira um componente

Um botão, um card, uma tag... Cada padrão que aparece várias vezes vira uma classe que você reusa. Menos código, mais consistência.

.btn.card.tag.avatar

Esse pensamento em blocos é o primeiro passo pro React, lá na frente.

responsividade · o mesmo design, toda tela

Mobile-first + media query

/* padrão: celular */
.galeria { grid-template-columns: 1fr; }

/* telas maiores */
@media (min-width: 600px) {
  .galeria { grid-template-columns: 1fr 1fr; }
}
