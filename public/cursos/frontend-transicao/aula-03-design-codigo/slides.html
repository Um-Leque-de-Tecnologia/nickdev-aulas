espaçamento · o segredo do "profissional"

padding · margin · gap

padding

espaço dentro da caixa.

margin

espaço fora da caixa.

gap

espaço entre itens de flex/grid.

Use múltiplos de 8 (8 · 16 · 24) — o "grid de 8pt" alinha tudo sem esforço.

flexbox · alinhar numa direção
{ display:flex }

Uma fileira ou coluna, com alinhamento e distribuição. Perfeito pra navbar: logo de um lado, menu do outro.

.nav-in {
  display: flex;
  justify-content: space-between;
  align-items: center;
}

grid · colunas de verdade
{ display:grid }

Pra galerias e cards lado a lado. auto-fill + minmax = colunas que se ajustam sozinhas (responsivo de graça).

  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));

Flexbox ou Grid?

Flexbox

Uma direção: uma fileira ou coluna. Ex.: a navbar.

Grid

Duas direções: uma grade. Ex.: o grid de projetos.

É uma fileira? Flex. É uma grade? Grid. E pode usar os dois juntos!

componentização · sem framework ainda

Reaproveitar: metade dá pra hoje

✅ O estilo

Uma classe CSS é um componente: .card escrito uma vez, usado em vários.

⚠️ A estrutura

Mas o HTML repete: você copia e cola o card 6 vezes. Essa é a dor.

Sintam a dor de copiar/colar hoje — é exatamente isso que o React vai resolver depois. 😏

o pulo do gato · usando o JS da aula 2

Componente = função que devolve HTML

// dados
const projetos = [{...}, {...}];

// o componente
function criarCard(p) {
  ...devolve um card...
}

// reaproveita a estrutura
projetos.forEach(p =>
  grid.appendChild(criarCard(p)));
resultado · 3 cards gerados de dados

1 função → N cards. Quando vir function Card() no React, vai ser "ah, é a mesma ideia!".

responsividade · o mesmo design, toda tela

Web → Mobile

O designer entrega as duas versões. Com media queries o grid vira menos colunas no celular.

@media (max-width:620px) {
  #grid { grid-template-columns:
    repeat(2, minmax(0,1fr)); }
}

minmax(0, 1fr) é o truque pra coluna encolher sem vazar pro lado.
