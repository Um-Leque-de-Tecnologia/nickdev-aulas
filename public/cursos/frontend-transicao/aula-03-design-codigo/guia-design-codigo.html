Do design ao código

Como olhar um layout com olho de dev e transformá-lo em página fiel. Sua cola de Flexbox, Grid, tokens e tipografia.

O olho de dev

Antes de escrever qualquer código, leia o design. Procure por:

  • Blocos — quais são as caixas grandes? (cada uma vira uma div)
  • Repetição — o que se repete? (vira um componente, tipo um card)
  • Alinhamento — está centralizado? à esquerda? em colunas?
  • Espaçamento — quanto de respiro entre os elementos?
  • Hierarquia — o que é título, o que é secundário? (tamanho e cor)
Truque: desenhe retângulos por cima do design (mentalmente ou no papel). Você acabou de descobrir sua estrutura HTML.

Design tokens

Designers definem uma paleta e tamanhos-padrão. No código, a gente guarda isso em variáveis CSS — muda num lugar, reflete em tudo.

:root {
  --rosa: #F24487;
  --roxo: #7B4FD0;
  --texto: #1B1830;
  --raio: 22px;
  --espaco: 16px;
}

/* usar em qualquer lugar: */
.card { background: var(--rosa); border-radius: var(--raio); }
Por que vale a pena: pra trocar o tema inteiro do site, você muda 5 variáveis em vez de caçar cor por cor.

Tipografia

Fonte e tamanhos criam a hierarquia. Pegue a fonte no Google Fonts e defina os tamanhos que viu no design.

<!-- no <head> -->
<link href="https://fonts.googleapis.com/css2?family=Poppins:wght@400;600;700" rel="stylesheet">

body { font-family: 'Poppins', sans-serif; }
h1 { font-size: 32px; font-weight: 700; }   /* título forte */
.legenda { font-size: 13px; color: #6B6580; } /* secundário */

Espaçamento

O que faz um layout parecer profissional é o respiro consistente. Três ferramentas:

  • padding — espaço dentro da caixa
  • margin — espaço fora da caixa
  • gap — espaço entre itens de um flex/grid
Dica de ouro: use múltiplos de um número (4 ou 8): 8px, 16px, 24px... Isso é o “grid de 8pt” que designers usam. Fica tudo alinhado sem esforço.

Flexbox — alinhar em linha ou coluna

Flexbox organiza itens num eixo (linha ou coluna). É o jeito mais fácil de centralizar e distribuir.

.barra {
  display: flex;
  justify-content: space-between; /* distribui no eixo principal */
  align-items: center;         /* centraliza no outro eixo */
  gap: 12px;
}
resultado
  • justify-content: center, space-between, space-around, flex-start
  • align-items: center, flex-start, stretch
  • flex-direction: column vira uma pilha vertical
  • flex-wrap: wrap deixa quebrar linha quando não couber

Grid — colunas e linhas de verdade

Quando você precisa de colunas (uma galeria, cards lado a lado), Grid é o ideal.

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 colunas iguais */
  gap: 12px;
}
resultado
  • 1fr = “uma fração” do espaço; repeat(3, 1fr) = 3 colunas iguais
  • repeat(auto-fit, minmax(120px, 1fr)) = colunas que se ajustam sozinhas (responsivo mágico!)
  • gap controla o espaço entre as células
Flex ou Grid? Uma direção (uma linha OU uma coluna) → Flexbox. Duas direções (linhas E colunas, uma grade) → Grid.

Imagens & assets

No Figma você exporta as imagens (PNG/SVG) e coloca na pasta do projeto.

<img src="foto.jpg" alt="Descrição da imagem">

img {
  width: 92px;
  height: 92px;
  border-radius: 50%;
  object-fit: cover;   /* recorta sem esticar */
}
  • SVG pra logos e ícones (não perde qualidade)
  • PNG/JPG pra fotos
  • object-fit: cover encaixa a foto no espaço sem distorcer
  • Sempre preencha o alt (acessibilidade!)

Componentização (sem framework)

"Componente" parece coisa de React — mas dá pra componentizar já no HTML/CSS/JS. Só que pela metade, e entender essa metade é o que faz o React fazer sentido depois.

Parte 1 — reaproveitar o estilo (dá pra hoje)

Uma classe CSS é um componente de estilo: escreve uma vez, usa em vários lugares.

.tag { background:#F3EEFC; color:var(--roxo); padding:6px 12px; border-radius:100px; }

<!-- o mesmo estilo, reaproveitado -->
<span class="tag">#dev</span>  <span class="tag">#design</span>

Parte 2 — a metade que falta: a estrutura

O estilo não repete, mas o HTML repete — você copia e cola <span class="tag"> pra cada tag. Essa dor é real, e é o que um framework resolve.

Deixe a turma sentir a repetição (copiar 6 cards na mão). É o melhor motivador pro React, onde a estrutura também é reaproveitada.

Parte 3 — o pulo do gato: componente = função que devolve HTML

Com o JavaScript da aula 2, dá pra reaproveitar a estrutura também: uma função cria o pedaço de HTML a partir de dados. Isso é um componente de verdade.

// os dados
const tags = ["#dev", "#design", "#café"];

// o COMPONENTE: uma função que devolve um elemento
function criarTag(texto) {
  const span = document.createElement("span");
  span.className = "tag";
  span.textContent = texto;
  return span;
}

// reaproveitando a estrutura (sem copiar e colar!)
tags.forEach(t => container.appendChild(criarTag(t)));
resultado
Ponte pro React: quando você vir function Tag() {} no React, vai reconhecer — é a mesma ideia, uma função que devolve um pedaço de tela.

Componentes que interagem

Um componente fica vivo quando reage. Alguns padrões que você vai usar muito (todos com eventos da aula 2):

Botão de curtir (estado + contador)

btn.addEventListener("click", () => {
  curtido = !curtido;                       // liga/desliga
  total += curtido ? 1 : -1;
  numero.textContent = total;
  btn.classList.toggle("ativo", curtido);
});
resultado clica ❤️

Filtro (mostrar/esconder por categoria)

// re-renderiza só com quem passa no filtro
const lista = projetos.filter(p => p.categoria === categoria);
render(lista);

Tema claro/escuro

botao.addEventListener("click", () =>
  document.body.classList.toggle("escuro")
);
Padrão que se repete: guardar um estado (curtido? tema? filtro?) e, no clique, atualizar o estado e a tela. É o coração de toda interface.

Bootstrap — não reinvente a roda 🅱️

Depois de aprender a montar o layout na mão (o card), dá pra acelerar com uma biblioteca de CSS pronta. O Bootstrap traz navbar, grid, cards e botões já estilizados — você usa as classes em vez de escrever tudo.

1. Incluir (uma linha no <head>)

<link rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css">

2. Grid responsivo pronto

Nada de media query na mão: row-cols-* define as colunas por tamanho de tela.

<div class="row row-cols-2 row-cols-md-4 row-cols-xl-6 g-3">
  <div class="col"> ...card... </div>
</div>

3. Card e botões prontos

<div class="card shadow-sm border-0">
  <div class="card-body">
    <h3 class="card-title h6">Título</h3>
    <button class="btn btn-sm btn-outline-secondary">Curtir</button>
  </div>
</div>

4. Dark mode nativo

O Bootstrap 5.3 já tem tema escuro. Só trocar o atributo no <html>:

document.documentElement.setAttribute("data-bs-theme", "dark");
E a componentização? Continua igual! O Bootstrap dá a aparência; a sua função criarCard() continua gerando os cards a partir dos dados. Biblioteca de estilo + componente por função = combo forte.
Quando usar? Bootstrap acelera muito, mas aprenda CSS primeiro (você já sabe 💜). Assim você entende o que a biblioteca faz e consegue customizar — em vez de ficar refém dela.

Responsividade

O mesmo design precisa funcionar no celular. Comece pensando mobile-first e ajuste em telas maiores com media queries.

/* padrão: celular (uma coluna) */
.galeria { grid-template-columns: 1fr; }

/* telas maiores: duas colunas */
@media (min-width: 600px) {
  .galeria { grid-template-columns: 1fr 1fr; }
}

Do Figma pro CSS — o passo a passo

Quando você tem o arquivo do Figma, o painel da direita (modo Inspect / Dev Mode) te dá quase tudo:

  • Cores — clique num elemento e copie o hex
  • Fontes — nome, tamanho e peso aparecem no painel
  • Medidas — selecione e veja largura, altura, raio
  • Espaçamento — segure Alt/Option e passe o mouse pra ver as distâncias
  • Exportar — botão direito → Export nas imagens/ícones
O segredo da fidelidade: deixe o design aberto ao lado do navegador e vá comparando. Ajuste até parecer a mesma coisa. Isso é o trabalho de verdade. 💜
