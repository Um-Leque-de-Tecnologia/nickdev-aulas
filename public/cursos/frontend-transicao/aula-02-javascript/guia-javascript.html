JavaScript do zero

Sua cola pra consultar durante a aula e o desafio. Cada trecho de código pode ser testado no Console do navegador (aperte F12).

Console & variáveis

console.log() mostra qualquer valor no console — é como o JS "fala" com você.

console.log("Oi, mundo! 👋");

Variáveis: let e const

Variável é uma caixinha com etiqueta que guarda um valor.

let pontos = 0;      // pode mudar depois
pontos = 10;

const nome = "Nick";  // fixo, não muda
Regra prática: use const sempre. Só troque pra let quando o valor realmente precisar mudar.

Tipos de dado

  • String — texto, entre aspas: "Nicoly"
  • Number — números, sem aspas: 25, 3.14
  • Boolean — true ou false
  • Array — lista: [1, 2, 3]
  • Object — ficha: { nome: "Nick" }
typeof "oi";   // "string"
typeof 25;     // "number"
typeof true;   // "boolean"

Strings & template literals

Pra juntar texto com variáveis, use crase (`) e ${ }:

const nome = "Ana";
const idade = 20;

// jeito antigo
"Oi, " + nome + ", " + idade + " anos";

// jeito moderno (template literal) 👇
`Oi, ${nome}, ${idade} anos`;

Métodos úteis de string

nome.toUpperCase();   // "ANA"
nome.length;         // 3
nome.includes("A");  // true

Operadores

  • Aritméticos: + - * / % (resto)
  • Comparação: === (igual) !== (diferente) > < >= <=
  • Lógicos: && (E) || (OU) ! (NÃO)
10 % 2;        // 0  → resto da divisão (par!)
7 === 7;       // true
idade >= 18 && temCarteira;  // as duas precisam ser true
Cuidado: = guarda um valor. === compara. São coisas diferentes!

Condicionais

Fazem o código decidir o caminho: "se isso, faça aquilo".

const hora = 14;

if (hora < 12) {
  console.log("Bom dia ☀️");
} else if (hora < 18) {
  console.log("Boa tarde 🌤️");
} else {
  console.log("Boa noite 🌙");
}

Atalho: operador ternário

const status = idade >= 18 ? "maior" : "menor";

switch: quando são vários valores fixos

Ótimo pra comparar uma variável com várias opções exatas — mais limpo que muitos else if.

const dia = "sábado";

switch (dia) {
  case "sábado":
  case "domingo":
    console.log("Fim de semana! 🎉");
    break;
  default:
    console.log("Dia útil 💻");
}
Não esqueça o break! Sem ele, o JS continua executando os próximos case. O default é o "senão" — roda quando nenhum case bate.

Funções

Uma receita reutilizável: recebe parâmetros e pode retornar um resultado.

// declaração
function saudar(nome) {
  return `Oi, ${nome}!`;
}

// arrow function (versão curta e moderna)
const saudar = (nome) => `Oi, ${nome}!`;

saudar("Nick");  // "Oi, Nick!"
return devolve o resultado pra quem chamou. Sem return, a função faz algo mas não "entrega" valor.

Arrays

Lista ordenada de valores. O primeiro item tem índice 0.

const hobbies = ["café", "código", "música"];

hobbies[0];          // "café"
hobbies.length;      // 3
hobbies.push("games");  // adiciona no fim

Descobrir o que tem dentro

hobbies.length;            // 3   → quantos itens
hobbies.includes("café");   // true → esse item existe?
hobbies.indexOf("música");   // 2   → em qual posição está
hobbies.at(-1);             // "música" → o último item
hobbies.some(h => h.length > 5);   // true  → ALGUM item passa no teste?
hobbies.every(h => h.length > 2);  // true  → TODOS passam?

Adicionar e remover

hobbies.push("games");    // adiciona no FIM
hobbies.pop();            // remove o ÚLTIMO (e devolve ele)
hobbies.unshift("chá");   // adiciona no INÍCIO
hobbies.shift();          // remove o PRIMEIRO
Macete: push/pop mexem no fim; shift/unshift mexem no início.

Percorrer e transformar

Estes recebem uma função e rodam ela pra cada item. Os 3 últimos criam uma lista nova (não mexem na original).

// forEach → faz algo com cada item (não devolve nada)
hobbies.forEach(h => console.log(h));

// map → NOVA lista transformada, item por item
const maiusculas = hobbies.map(h => h.toUpperCase());  // ["CAFÉ", ...]

// filter → NOVA lista só com quem passa no teste
const curtos = hobbies.filter(h => h.length <= 4);  // ["café", "chá"]

// find → o PRIMEIRO item que bate (ou undefined)
const achado = hobbies.find(h => h.startsWith("c"));  // "café"

Resumir e organizar

// reduce → junta tudo num só valor (ex.: somar)
const numeros = [10, 20, 30];
const total = numeros.reduce((soma, n) => soma + n, 0);  // 60

hobbies.sort();          // ordena (alfabética por padrão)
hobbies.reverse();       // inverte a ordem
hobbies.slice(0, 2);     // PEDAÇO: ["café", "código"] (não altera o original)
hobbies.join(", ");      // vira texto: "café, código, música"

Bônus: item aleatório

const sorteado = hobbies[Math.floor(Math.random() * hobbies.length)];
Cuidado — muda ou não muda? push, pop, shift, unshift, sort, reverse e splice alteram o array original. Já map, filter, slice e join devolvem algo novo e deixam o original em paz.

Loops

Repetir uma ação sem copiar e colar.

// for clássico
for (let i = 0; i < 3; i++) {
  console.log(i);   // 0, 1, 2
}

// for...of (percorre uma lista)
for (const hobby of hobbies) {
  console.log(hobby);
}

Objetos

Agrupam dados relacionados em pares chave: valor.

const pessoa = {
  nome: "Nicoly",
  idade: 25,
  dev: true,
};

pessoa.nome;        // "Nicoly"
pessoa.idade = 26;   // alterar
pessoa.cidade = "SP"; // adicionar

DOM — controlando o HTML

O DOM é a página vista como objetos. Com JS você seleciona um elemento e transforma ele.

// selecionar (usa seletor de CSS)
const titulo = document.querySelector("h1");
const botao  = document.querySelector("#meu-botao");

// mudar
titulo.textContent = "Texto novo";   // o conteúdo
titulo.style.color = "hotpink";     // o estilo
titulo.classList.toggle("escuro"); // liga/desliga classe CSS
  • textContent — o texto de dentro
  • value — o que foi digitado num <input>
  • classList.add / remove / toggle — mexe nas classes CSS

Eventos

Fazem a página reagir: "quando acontecer X, execute Y".

botao.addEventListener("click", () => {
  console.log("Clicou! 🎉");
});

// ler o que o usuário digita, ao vivo
input.addEventListener("input", () => {
  console.log(input.value);
});

Eventos comuns: click, input, submit, mouseover, keydown.

Prática — juntando tudo

Um botão que troca o texto de um parágrafo ao ser clicado:

<!-- HTML -->
<button id="btn">Clique</button>
<p id="msg">Nada ainda...</p>

// JavaScript
const btn = document.querySelector("#btn");
const msg = document.querySelector("#msg");

btn.addEventListener("click", () => {
  msg.textContent = "Você clicou! ✨";
});

Node & npm

Calma: pro desafio de hoje você não precisa disto — tudo roda no navegador. Esta parte é um mapa do que vem nas próximas aulas, quando os projetos crescem.

Por que sair do navegador?

Até agora o JavaScript rodou dentro do navegador. O Node.js é um programa que roda JavaScript fora dele — no seu computador, direto no terminal. É o que permite usar ferramentas, servidores e projetos maiores (tipo o próprio site de vocês, feito em Next.js 👀).

1. Instalar o Node

Baixe a versão LTS em nodejs.org e instale (é só avançar). Depois, confira no terminal:

# mostra a versão instalada (se aparecer um número, deu certo)
node -v
npm -v

O npm (Node Package Manager) já vem junto com o Node. É ele que baixa e organiza os "pacotes" (códigos prontos de outras pessoas).

2. Começar um projeto

# cria o package.json (a "carteira de identidade" do projeto)
npm init -y

# instala um pacote (ex.: a biblioteca de datas)
npm install dayjs
  • package.json — lista o nome do projeto, os scripts e as dependências.
  • node_modules/ — pasta onde o npm guarda os pacotes baixados. Nunca se mexe nela na mão (e não sobe pro Git).
  • package-lock.json — trava as versões exatas, pra funcionar igual na máquina de todo mundo.

3. Rodar comandos (scripts)

No package.json você define atalhos na parte "scripts" e roda com npm run:

// dentro do package.json
"scripts": {
  "dev": "next dev"
}

# no terminal:
npm run dev
Você já viu isso! É exatamente assim que o site da NickDev roda: npm install pra baixar tudo e npm run dev pra ligar.

Módulos: import / export

Quando o código cresce, a gente separa ele em vários arquivos — cada um cuidando de uma coisa. Um arquivo exporta o que quer compartilhar; o outro importa o que precisa.

Exportar (arquivo saudacoes.js)

// export nomeado: pode exportar vários
export function bomDia(nome) {
  return `Bom dia, ${nome}!`;
}

export const emoji = "👋";

Importar (arquivo app.js)

import { bomDia, emoji } from "./saudacoes.js";

console.log(bomDia("Ana") + emoji);

Export default (um "principal" por arquivo)

// botao.js
export default function Botao() { ... }

// outro arquivo — importa sem chaves e escolhe o nome
import Botao from "./botao.js";
No navegador: pra usar import direto no HTML, a tag precisa ser <script type="module">. Em projetos com Node/Next, isso já vem configurado. É assim que o site de vocês junta os componentes (import SiteHeader from ...).
