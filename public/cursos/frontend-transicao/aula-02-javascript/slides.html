javascript · a linguagem da web
<js> quem faz reagir

JavaScript é a linguagem que todo navegador entende. É ela que faz o botão clicar, o menu abrir, o formulário validar, o carrinho somar.

E o melhor: pra começar você não precisa instalar nada. O navegador já vem com ele.

Onde ele roda?

  • No navegador (Chrome, Firefox...)
  • Dentro de <script> no HTML
  • No Console — nosso laboratório de hoje

variáveis · caixinhas com etiqueta

Guardando informação: let e const

let

uma caixa que pode mudar de valor depois.

let pontos = 0
pontos = 10 // pode!

const

uma caixa fixa — o valor não muda.

const nome = "Nick"
// mudar dá erro ⚠️

Dica de ouro: use const por padrão. Só troque pra let quando precisar mudar o valor.

tipos · os "sabores" de dado

Três tipos que resolvem quase tudo

String 🔤

texto, sempre entre aspas.

"Nicoly"

Number 🔢

números (sem aspas!).

25   3.14

Boolean ✅

verdadeiro ou falso.

true   false

No console, typeof "oi" te diz o tipo de qualquer valor.

Template literals: o jeito elegante

O jeito antigo (+)

"Oi, " + nome + "! Você tem " + idade + " anos"

O jeito novo (crase + ${})

`Oi, ${nome}! Você tem ${idade} anos`

Use crase (`) no lugar das aspas e coloque variáveis dentro de ${ }. Bem mais limpo!

operadores · as ferramentas

Fazendo contas e comparações

Aritméticos

+   -   *   /   %

soma, subtrai, multiplica, divide. % é o resto.

Comparação

===   !==   >   <

devolvem true ou false.

Lógicos

&&   ||   !

E, OU, NÃO — pra combinar condições.

Atenção: = atribui (guarda na variável). === compara se é igual. Não confunda!

if / else · o JS tomando decisões

"Se isso, faça aquilo"

funções · blocos reutilizáveis

Ensinando o computador a fazer algo

Uma função é uma receita: você dá um nome, ela guarda os passos, e você chama quando quiser — quantas vezes quiser.

Recebe parâmetros (entradas) e pode retornar um resultado.

Uma função de verdade

function saudar(nome) {
  return `Oi, ${nome}!`
}

saudar("Ana") // "Oi, Ana!"

Versão moderna e curtinha (arrow function): const saudar = (nome) => `Oi, ${nome}!`

arrays · listas de coisas

Uma variável, vários valores

const hobbies = ["café", "código", "música"]

hobbies[0] // "café" (conta do zero!)
hobbies.length // 3 (quantos itens)
hobbies.push("games") // adiciona no fim

Array = lista ordenada. O primeiro item é o de índice 0.

loops · repetir sem copiar e colar

Fazendo o mesmo, pra cada item

for clássico

for (let i = 0; i < 3; i++) {
  console.log(i)
}

forEach (mais fácil)

hobbies.forEach(h => {
  console.log(h)
})

Loop é pra quando você quer repetir uma ação — tipo criar um card pra cada item de uma lista.

DOM · onde o JS encontra o HTML
<dom> a ponte

Quando a página carrega, o navegador transforma seu HTML numa árvore de objetos — o DOM. E o JavaScript consegue mexer em cada pedacinho dela: ler, mudar texto, cor, esconder, criar...

É isso que faz a página viva.

document.querySelector · pega e transforma

Selecionar → mudar

// 1. pega o elemento pelo seletor CSS
const titulo = document.querySelector("h1")

// 2. muda o que quiser
titulo.textContent = "Texto novo!" // o conteúdo
titulo.style.color = "hotpink" // o estilo
titulo.classList.add("ativo") // uma classe CSS
eventos · a página reage a você

"Quando acontecer X, faça Y"

const botao = document.querySelector("button")

botao.addEventListener("click", () => {
  console.log("Clicou! 🎉")
})
