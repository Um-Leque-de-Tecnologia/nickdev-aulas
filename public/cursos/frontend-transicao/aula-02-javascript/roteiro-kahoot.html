Material do professor · Aula 02

Roteiro do Kahoot ⚡

Quiz relâmpago de JavaScript pra rodar no slide do Kahoot (logo antes do almoço). As respostas certas estão marcadas com ✓ — é material seu, não projete esta página pra turma.

Como montar (5 min)

  1. Entre em kahoot.com/create → Quiz.
  2. Digite cada pergunta e as 4 alternativas; marque a correta.
  3. Deixe 20s nas fáceis e 30s nas “pegadinhas”.
  4. Modo Classic (cada um no seu celular). Projete o PIN.
  5. Depois de cada pergunta, comente a resposta usando a nota do professor. É aí que o aprendizado gruda.
Quiz principal · 12 perguntas · fundamentos da manhã

Cobre console, variáveis, tipos, template literals, operadores e if/else — tudo que já foi visto quando o Kahoot acontece.

01Qual comando mostra algo no console?
✓console.log()
Bprint()
Cconsole.show()
Dwrite()
⏱ 20sNota: é o “olá mundo” do JS. Todo mundo já usou hoje.
02Qual palavra cria uma variável que não pode mudar de valor?
✓const
Blet
Cvar
Dfixed
⏱ 20sNota: reforce a regra: const por padrão, let só quando muda.
03Qual valor é do tipo string?
✓"Oi"
B42
Ctrue
D3.14
⏱ 20sNota: string = texto, sempre entre aspas. O resto é number/boolean.
04Quanto vale 10 % 3? (o operador resto)
✓1
B3
C0
D3.33
⏱ 30sNota: % dá o resto da divisão (10 ÷ 3 = 3, sobra 1). Serve pra testar par/ímpar.
05O que aparece? console.log(typeof "oi")
✓"string"
B"oi"
C"number"
D"texto"
⏱ 25sNota: typeof revela o tipo de qualquer valor. Ótimo pra debugar.
06Qual operador compara se dois valores são iguais?
✓===
B=
C=>
D=!
⏱ 25sNota: pegadinha clássica: = guarda valor, === compara. Não confundir!
07Com nome = "Ana", qual é um template literal certo?
✓`Oi, ${nome}`
B"Oi, ${nome}"
C`Oi, {nome}`
D'Oi, $nome'
⏱ 30sNota: precisa de crase (`) E de ${ }. Aspas normais não interpolam.
08let idade = 17. No if (idade >= 18) {...} else {...}, qual bloco roda?
✓o else
Bo if
Cos dois
Dnenhum
⏱ 25sNota: 17 não é ≥ 18 → a condição é false → cai no else.
09O que mostra console.log(2 + "2")?
✓"22"
B4
C22 (número)
Derro
⏱ 30sNota: a pegadinha do dia! number + string vira texto (junta em vez de somar).
10Qual operador significa “E” (as duas condições verdadeiras)?
✓&&
B||
C!
D+
⏱ 20sNota: && = E, || = OU, ! = NÃO.
11Qual o resultado de true && false?
✓false
Btrue
Cundefined
Derro
⏱ 25sNota: no “E”, basta um false pra tudo virar false.
12Qual linha está certa pra uma variável que vai mudar de valor?
✓let pontos = 0
Bconst pontos = 0
Cvariable pontos = 0
Dpontos := 0
⏱ 25sNota: fecha o tema variáveis. const daria erro ao tentar mudar depois.
Rodada bônus · 6 perguntas · funções, arrays, DOM & eventos

Use se sobrar tempo no fim do dia, como um segundo Kahoot depois do bloco da tarde. Não aplique antes de ensinar esses temas.

B1Em const lista = ["a","b","c"], como pegar o primeiro item?
✓lista[0]
Blista[1]
Clista.first
Dlista(0)
⏱ 25sNota: array conta do zero. O primeiro é o índice 0.
B2Qual sintaxe cria uma função?
✓function saudar() {}
Bfunc saudar() {}
Cdef saudar():
Dcreate saudar() {}
⏱ 20sNota: cite também a arrow: const saudar = () => {}.
B3O que document.querySelector("#nome") faz?
✓pega o elemento com id “nome”
Bcria um elemento novo
Capaga o elemento
Dpega todos os parágrafos
⏱ 25sNota: usa seletor de CSS. # é id, . é classe.
B4Como rodar um código quando clicarem num botão?
✓btn.addEventListener("click", ...)
Bbtn.onClick = true
Cbtn.click()
Dif (btn) {}
⏱ 30sNota: evento = “quando acontecer X, faça Y”. O coração da interatividade.
B5Quantas vezes roda? for (let i = 0; i < 3; i++)
✓3 vezes
B2 vezes
C4 vezes
Dinfinitas
⏱ 30sNota: i vale 0, 1 e 2 (para quando chega em 3). Conta do zero de novo!
B6O que Math.random() devolve?
✓um número entre 0 e 1
Bum inteiro qualquer
Csempre 0
Duma letra aleatória
⏱ 25sNota: ligue ao desafio: é assim que se sorteia a curiosidade aleatória.
Dicas de condução 🎤
• Faça um “pódio” no fim e dê um miojo simbólico pro top 3. 😄
• Errou muita gente numa pergunta? Volte 30s no conceito antes de seguir.
• As pegadinhas (04, 06, 09) são as mais valiosas — reserve tempo pra explicar.
• Quem terminar o quiz rápido pode ajudar quem está com dúvida.
