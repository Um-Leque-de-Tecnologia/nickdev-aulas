☀️ Parte 1 · Desafios da manhã (no console)
1

Cartão de visita

Variáveis + template literal.

const nome = "Nicoly Almeida";
const profissao = "desenvolvedora";

console.log(`Oi! Sou a ${nome}, ${profissao}.`);
// → Oi! Sou a Nicoly Almeida, desenvolvedora.
2

Par ou ímpar

Operador resto (%) + if / else.

const numero = 7;

if (numero % 2 === 0) {
  console.log(numero + " é par");
} else {
  console.log(numero + " é ímpar");
}
// → 7 é ímpar
3

Boletim

Comparação (>=) + if / else.

const nota = 8;

if (nota >= 7) {
  console.log("Aprovado ✅");
} else {
  console.log("Recuperação 📚");
}
// → Aprovado ✅
4

Que dia é hoje?

switch / case com default (repare nos case empilhados).

const dia = "sexta";

switch (dia) {
  case "sexta":
    console.log("Sextou! 🎉");
    break;
  case "sábado":
  case "domingo":
    console.log("Fim de semana 😎");
    break;
  default:
    console.log("Bora estudar 💻");
}
// → Sextou! 🎉

Desafio turbo · Loja com cupom

Number + boolean + condicional + operador + template literal.

const preco = 100;
const temCupom = true;

let precoFinal = preco;
if (temCupom) {
  precoFinal = preco * 0.9;   // 10% de desconto
}

console.log(`Você paga R$ ${precoFinal}`);
// → Você paga R$ 90
🔮 Parte 2 · Desafio principal — o site interativo

O site “sobre mim” que reage a você, quebrado em pedaços. Junte tudo num index.html (o CSS no <style> e o JS no <script>, no fim do <body>).

1 · HTML — a estrutura

Os elementos com id são os que o JavaScript vai controlar.

<!-- botão de tema, fica no canto -->
<button id="tema">🌙</button>

<header>
  <p id="saudacao"></p>         <!-- o JS preenche -->
  <h1>Nicoly Almeida</h1>
  <input id="campo-nome" placeholder="digite seu nome">
</header>

<button id="btn-curiosidade">Revelar curiosidade 🎲</button>
<p id="curiosidade"></p>

<ul id="lista-hobbies"></ul>    <!-- o JS cria os itens -->

2 · CSS — o tema claro

O JS só liga/desliga a classe .claro; o CSS cuida da aparência.

body {
  background: #0f0c17;
  color: #f3f0fa;
  transition: .3s;        /* troca suave */
}

/* quando o body tem a classe .claro */
body.claro {
  background: #f4f1fa;
  color: #1a1626;
}

3 · JS — Saudação pela hora

Date + uma função com if / else + DOM.

const hora = new Date().getHours();

function saudacaoPara(h) {
  if (h < 12) return "Bom dia ☀️";
  if (h < 18) return "Boa tarde 🌤️";
  return "Boa noite 🌙";
}

document.querySelector("#saudacao").textContent = saudacaoPara(hora);

4 · JS — Nome ao vivo (extra)

Evento input: a saudação muda enquanto a pessoa digita.

const campoNome = document.querySelector("#campo-nome");
const elSaudacao = document.querySelector("#saudacao");

campoNome.addEventListener("input", () => {
  const nome = campoNome.value;
  if (nome === "") {
    elSaudacao.textContent = saudacaoPara(hora);
  } else {
    elSaudacao.textContent = saudacaoPara(hora) + ", " + nome + "!";
  }
});

5 · JS — Curiosidade aleatória

Array + Math.random + evento click + contador.

const curiosidades = [
  "Amo um café enquanto codo ☕",
  "Já dei aula pra mais de 100 pessoas 👩‍🏫",
  "Aprendi a programar depois de adulta 🚀",
];

const btn = document.querySelector("#btn-curiosidade");
const alvo = document.querySelector("#curiosidade");

btn.addEventListener("click", () => {
  const i = Math.floor(Math.random() * curiosidades.length);
  alvo.textContent = curiosidades[i];
});

6 · JS — Lista de hobbies (loop)

forEach + createElement + appendChild.

const hobbies = ["Ensinar", "Café", "Design bonito", "Comunidade"];
const lista = document.querySelector("#lista-hobbies");

hobbies.forEach((hobby) => {
  const li = document.createElement("li");
  li.textContent = hobby;
  lista.appendChild(li);
});

7 · JS — Tema claro/escuro

classList.toggle + troca do ícone.

const botaoTema = document.querySelector("#tema");

botaoTema.addEventListener("click", () => {
  document.body.classList.toggle("claro");

  if (document.body.classList.contains("claro")) {
    botaoTema.textContent = "☀️";
  } else {
    botaoTema.textContent = "🌙";
  }
});
