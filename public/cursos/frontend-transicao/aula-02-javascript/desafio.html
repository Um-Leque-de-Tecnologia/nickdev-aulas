Desafio · Aula 02

Seu site ganha vida 🔮

Lembra do seu site “sobre mim” da aula passada? Hoje ele vira interativo. Você vai adicionar JavaScript pra ele reagir a quem visita — botões que respondem, textos que mudam, tema que troca. E publicar tudo de novo. 🚀

🎯

O objetivo

Deixar seu site “sobre mim” vivo: uma saudação que muda com a hora, um botão de curiosidade aleatória e um botão de tema claro/escuro.

Passo a passo
01

Ligue o JavaScript

No seu index.html, adicione um <script> logo antes de fechar o </body>:

  <!-- ...seu conteúdo... -->

  <script>
    console.log("JS ligado! 🎉");
  </script>
</body>

Confira: abra o site, aperte F12 → Console. Viu a mensagem? Tá funcionando!

02

Botão de curiosidade aleatória

Guarde curiosidades num array e mostre uma sorteada quando clicarem no botão. Você vai usar array, função, evento e DOM:

<button id="btn-curiosidade">Me conheça 👀</button>
<p id="curiosidade"></p>

<script>
  const fatos = ["Amo café ☕", "Já morei em 3 cidades", "Toco violão"];
  const btn = document.querySelector("#btn-curiosidade");
  const alvo = document.querySelector("#curiosidade");

  btn.addEventListener("click", () => {
    const i = Math.floor(Math.random() * fatos.length);
    alvo.textContent = fatos[i];
  });
</script>
03

Saudação pela hora do dia

Use Date e if/else pra dar bom dia, boa tarde ou boa noite automaticamente:

const hora = new Date().getHours();
let saudacao;

if (hora < 12)      saudacao = "Bom dia ☀️";
else if (hora < 18) saudacao = "Boa tarde 🌤️";
else               saudacao = "Boa noite 🌙";

document.querySelector("#saudacao").textContent = saudacao;
04

Tema claro/escuro

Um botão que liga e desliga uma classe CSS no <body> com classList.toggle:

/* no CSS */
body.claro { background: #fff; color: #1a1a2e; }

// no JS
const botaoTema = document.querySelector("#tema");
botaoTema.addEventListener("click", () => {
  document.body.classList.toggle("claro");
});

Dica: toggle adiciona a classe se não tiver, e remove se já tiver. Perfeito pra ligar/desligar.

05

Publique na internet

Faça git push e a Vercel republica sozinha — igual na aula 1. Mande o link no grupo pra galera testar seu site interativo! 🌍

Requisitos mínimos
  • JavaScript ligado no HTML (via <script>)
  • Um array com pelo menos 3 curiosidades suas
  • Um botão que mostra uma curiosidade aleatória ao ser clicado
  • Uma saudação que muda conforme a hora (usando if/else)
  • Um botão de tema claro/escuro funcionando
  • Pelo menos uma função criada por você
  • Publicado na Vercel com link funcionando
Desafios extras (pra quem quer brilhar ✨)
  • Um campo de nome que personaliza a saudação ao vivo (evento input)
  • Um contador: quantas curiosidades a pessoa já revelou
  • Uma lista de hobbies criada com loop (forEach) em vez de digitar um a um
  • Evitar repetir a mesma curiosidade duas vezes seguidas
  • Salvar o tema escolhido com localStorage (pesquise! 🔎)
