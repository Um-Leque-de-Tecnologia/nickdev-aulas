O que é um framework?

Biblioteca 📚

Você chama ela. Ex.: Bootstrap — "me dá um card bonito".

Framework 🏗️

Ela chama você. Define a estrutura, e você preenche os espaços.

Analogia: biblioteca é comprar um móvel pronto. Framework é alugar um apartamento mobiliado — já vem com regra de onde cada coisa fica.

react · o que você já sabia sem saber

Componente = função que devolve tela

🗓️ aula 03 — na mão 
function criarCard(p) {
  const div = document.createElement("div");
  div.innerHTML = `
    <h3>${p.titulo}</h3>
    <p>${p.empresa}</p>`;
  return div;
}
✨ hoje — React 
function VagaCard({ vaga }) {
  return (
    <article>
      <h3>{vaga.titulo}</h3>
      <p>{vaga.empresa}</p>
    </article>
  );
}

É a mesma ideia. Só que agora o HTML é nativo dentro do JavaScript e o React cuida de colocar na tela.

props · os "parâmetros" do componente

Um componente, vários resultados

// o componente recebe dados...
function Selo({ texto, cor }) {
  return <span style={{ color: cor }}>{texto}</span>;
}

// ...e você usa como se fosse uma tag HTML
<Selo texto="Remoto" cor="#A98CE0" />
<Selo texto="Júnior" cor="#F24487" />

props = argumentos

Igualzinho aos parâmetros de função da aula 02. Escreve uma vez, usa mil.

Componente com letra maiúscula

<Selo /> é seu componente. <span /> é HTML. O React diferencia pela maiúscula!

listas · o .map() da aula 02 volta

Um array vira uma tela

const vagas = [{ titulo: "Front-end Jr" }, { titulo: "Estágio QA" }];

<div>
  {vagas.map((vaga) => (
    <VagaCard key={vaga.slug} vaga={vaga} />

key é obrigatória: é o "RG" de cada item. Sem ela, o React se perde quando a lista muda de ordem.

app router · a parte que encanta

Pasta = rota. Só isso.

Você cria o arquivoO site ganha a URL

app/sobre/page.tsx/sobre
app/vagas/page.tsx/vagas

Não existe arquivo de configuração de rotas. Você cria a pasta, a rota existe.

nomes reservados · o Next entende sozinho

Os 5 arquivos mágicos

page.tsx

a página em si. Sem ela, a pasta não vira rota.

layout.tsx

a moldura ao redor. Não remonta ao navegar.

loading.tsx

aparece sozinho enquanto a página busca dados.

error.tsx

rede de proteção: algo quebrou, o site não cai.

not-found.tsx

o seu 404, com a cara do seu projeto.

✨ o pulo

Você nunca escreve if (carregando). Basta o arquivo existir.

layout · adeus, cabeçalho copiado em 8 arquivos

Escreva o menu uma vez

📄 app/layout.tsx 
export default function RootLayout({ children }) {
  return (
    <html lang="pt-BR">
      <body>
        <Cabecalho />
        <main>{children}</main>   ← a página entra aqui
        <Rodape />
      </body>
    </html>
  );
}

Navegou de /vagas pra /sobre? O layout não é remontado — só o children troca. Por isso o cabeçalho não pisca.

navegação · a diferença que dá pra sentir

<Link> em vez de <a>

<a href="/vagas">

Recarrega o site inteiro. Tela branca, tudo do zero.

<Link href="/vagas">

Troca só o que mudou. E já baixa a página antes de você clicar (prefetch).

import Link from "next/link";

<Link href="/vagas">Ver as vagas</Link>
<Link href={`/vagas/${vaga.slug}`}>{vaga.titulo}</Link>

Regra: link interno → sempre <Link>. Link pra fora do seu site → <a> normal.

Quem acessavê o conteúdo na hora

No App Router, todo componente é de servidor por padrão. Ele não manda JavaScript nenhum pro navegador — a página fica leve e o Google lê o conteúdo.

buscar dados · sem useEffect, sem fetch no navegador

await direto no componente

📄 app/vagas/page.tsx 
export default async function PaginaVagas() {
  const vagas = await listarVagas();   ← roda no servidor!

  return <div>{vagas.map(v => <VagaCard key={v.slug} vaga={v} />)}</div>;
}

É só colocar async na função e usar await. Como roda no servidor, dá pra falar com banco de dados e usar senha de API sem expor nada.

"use client" · quando o navegador precisa participar

O componente que interage

📄 components/SalvarButton.tsx 
"use client";   ← primeira linha do arquivo

import { useState } from "react";

export default function SalvarButton() {
  const [salva, setSalva] = useState(false);

  return (
    <button onClick={() => setSalva(!salva)}>
      {salva ? "★" : "☆"}
    </button>
  );
}

Precisa de "use client" quando tem:

useState · useEffect · onClick · localStorage · window

resultado · clica na estrela
a regra de bolso · cola isso na parede

Servidor ou Cliente?

Preciso de…Componente
Buscar dados, ler banco, usar chave secretaServidor (padrão)
Só mostrar conteúdoServidor (padrão)
useState — algo que muda na telaCliente
onClick, onChange — eventosCliente
localStorage, window, animaçãoCliente

Comece sempre no servidor. Só coloque "use client" quando o Next reclamar — e ele reclama com uma mensagem bem clara.

arquitetura · o erro mais comum de quem começa

Empurre o "use client" pra baixo

❌ "use client" na página

A página inteira e tudo dentro dela viram cliente. Adeus HTML leve.

✅ "use client" no botãozinho

Só a estrela é cliente. O card, a lista e a página continuam no servidor.

No nosso projeto: 1 único arquivo tem "use client" — o SalvarButton. Todo o resto é servidor.

loading.tsx · carregamento sem escrever um if

O esqueleto que aparece sozinho

📄 app/vagas/loading.tsx 
export default function Carregando() {
  return <p>carregando vagas…</p>;
}

Pronto. Enquanto o page.tsx da mesma pasta busca os dados, o Next mostra isso automaticamente e troca quando ficar pronto.

Dica de UX: em vez de "carregando…", desenhe retângulos cinzas no formato dos cards (skeleton). A espera parece menor.

[slug] · uma pasta, infinitas páginas

Rota dinâmica

📄 app/vagas/[slug]/page.tsx 
export default async function PaginaVaga({ params }) {
  const { slug } = await params;        ← Next 16: params é Promise!
  const vaga = await buscarVagaPorSlug(slug);

  if (!vaga) notFound();               ← mostra o not-found.tsx

  return <h1>{vaga.titulo}</h1>;
}

9 vagas no array = 9 páginas no site, e você escreveu 1 arquivo. Adicionou a décima vaga? A página já existe.

metadata · o link bonito no WhatsApp

SEO sem escrever <head>

// página fixa
export const metadata = {
  title: "Vagas",
  description: "Todas as vagas do mural.",
};

// página dinâmica
export async function generateMetadata({ params }) {
  const { slug } = await params;
  const vaga = await buscarVagaPorSlug(slug);
  return { title: vaga.titulo, description: vaga.resumo };
}

generateStaticParams

Diz ao Next quais slugs existem → ele pré-gera as páginas no build. Ficam instantâneas.

Por que importa?

É o que faz sua vaga aparecer bonita no Google e no preview do WhatsApp/LinkedIn.
