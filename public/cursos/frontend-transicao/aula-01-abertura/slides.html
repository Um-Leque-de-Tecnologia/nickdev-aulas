html · HyperText Markup Language
<html> o esqueleto

Tudo em HTML é tag: uma que abre e uma que fecha, com o conteúdo no meio.

<h1>Meu título</h1>

Cada tag tem um sentido: <h1> é título, <p> é parágrafo, <img> é imagem, <a> é link.

Anatomia de uma tag

<a href="https://...">
  clique aqui
</a>

experimenta · edite à esquerda, veja acontecer à direita

css · Cascading Style Sheets
<css> deixando bonito

CSS escolhe um elemento e diz como ele deve parecer:

h1 {
  color: tomato;
  font-size: 40px;
}

E toda caixa na tela segue o box model → é o que você vê ao lado. Passe o mouse pra sentir as camadas.

git · a máquina do tempo do seu código
<git> salvando seu progresso

Pensa no Git como o "save game" da sua vida de dev. Cada ponto salvo é um commit — e você pode voltar pra qualquer um.

  • repositório — a pasta do projeto que o Git observa
  • commit — uma foto do código naquele momento
  • push — mandar seus commits pra nuvem (GitHub)

A linha do tempo

deploy · do seu computador pra internet

Colocando seu site no ar com a Vercel

Suba o projeto pro GitHub

Seu repositório com o index.html vira a fonte da verdade.

Entre na Vercel com o GitHub

Em vercel.com, login com a conta do GitHub — sem cartão, sem burocracia.

Importe o repositório

"Add New Project" → escolhe o repo → Deploy. A Vercel faz o resto.

Receba seu link no ar 🌍

Em segundos você ganha uma URL pública tipo seu-site.vercel.app.

Bônus: todo push novo no GitHub atualiza o site sozinho. Você muda o código, ele republica.
