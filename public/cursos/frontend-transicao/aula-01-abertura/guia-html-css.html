Sua cola completa pra consultar sempre que precisar. Cada tag e cada propriedade tem explicação e exemplo pronto pra copiar. Passe o mouse num bloco de código e clique em copiar.

htmlEstrutura base de uma página

Todo arquivo HTML começa com esse esqueleto. É o mínimo pro navegador entender que aquilo é uma página web.

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Minha Página</title>
  </head>
  <body>
    <!-- tudo que aparece na tela vai aqui -->
    <h1>Olá, mundo!</h1>
  </body>
</html>
<!DOCTYPE html>avisa o navegador que é HTML moderno. Sempre a primeira linha.
<html lang>envolve a página inteira. lang define o idioma.
<head>informações que não aparecem na tela: título, codificação, links de CSS.
<meta charset>UTF-8 garante que acentos e emojis funcionem.
<meta viewport>faz o site se comportar bem no celular. Essencial pra responsividade.
<title>o texto que aparece na aba do navegador.
<body>todo o conteúdo visível da página.

htmlTexto

As tags mais usadas do dia a dia. Servem pra dar significado ao texto — não é só "deixar grande" ou "deixar negrito", é dizer o que cada coisa é.

<h1> até <h6> — títulos

Títulos e subtítulos, do mais importante (h1) ao menos (h6). Use só um h1 por página.

<h1>Título principal</h1>
<h2>Um subtítulo</h2>
<h3>Menor ainda</h3>
resultado

<p> — parágrafo

Um bloco de texto comum. O navegador dá um espaçamento antes e depois automaticamente.

<p>Este é um parágrafo de texto normal
que pode ter várias linhas.</p>
resultado

<strong>, <em>, <span>

strong dá ênfase forte (negrito), em dá ênfase (itálico), e span é um trecho neutro pra você estilizar depois com CSS.

<p>Isso é <strong>muito importante</strong>
e isso é <em>um destaque</em>.</p>
resultado

<br> e <hr>

br quebra a linha; hr desenha uma linha divisória. As duas não têm tag de fechamento.

Primeira linha<br>Segunda linha
<hr>
Depois da divisória

htmlLinks e imagens

<a> — link (âncora)

O atributo href diz pra onde vai. target="_blank" abre em nova aba.

<a href="https://google.com" target="_blank">
  Ir pro Google
</a>
resultado

<img> — imagem

Não tem fechamento. src é o caminho da imagem, e alt é o texto alternativo — sempre descreva a imagem (acessibilidade + SEO).

<img src="foto.jpg" alt="Retrato de uma pessoa sorrindo" width="200">

htmlÁudio e vídeo

Reprodução nativa, sem plugin. O atributo controls mostra os botões de play/pause.

<video src="aula.mp4" controls width="400"></video>

<audio src="musica.mp3" controls></audio>

htmlEstrutura semântica

O <div> é uma caixa genérica. As tags semânticas são caixas com significado — ajudam leitores de tela, o Google e outros devs a entender seu layout.

<header>Topo: logo e menu</header>
<nav>Links de navegação</nav>
<main>
  <section>
    <article>Conteúdo principal</article>
  </section>
  <aside>Barra lateral</aside>
</main>
<footer>Rodapé</footer>
resultado
<div>caixa genérica, sem significado. Use quando nenhuma semântica se encaixa.
<header>topo da página ou de uma seção.
<nav>bloco de navegação (menu).
<main>o conteúdo principal — só um por página.
<section>uma seção temática do conteúdo.
<article>conteúdo independente (um post, um card).
<aside>conteúdo lateral/complementar.
<footer>rodapé.

Onde o usuário digita coisas. O <label> descreve cada campo e melhora muito a acessibilidade.

<form>

  <label>E-mail:</label>
  <input type="email">

  <textarea placeholder="Mensagem"></textarea>

  <select>
    <option>Manhã</option>

  </select>

resultado
type="text"campo de texto simples.
type="email"valida formato de e-mail.
type="password"esconde o que é digitado.

type="radio"escolha única entre opções.

cssComo aplicar CSS

Três formas — mas o jeito profissional é o arquivo separado. A regra é sempre: seletor { propriedade: valor; }

/* 1. arquivo separado (recomendado) — no <head> do HTML: */
<link rel="stylesheet" href="style.css">

/* 2. no próprio HTML, dentro de <style> */
/* 3. inline (evite): <p style="color:red"> */

/* anatomia de uma regra: */
h1 {
  color: tomato;
  font-size: 40px;
}

cssSeletores

Como você escolhe quem vai receber o estilo.

p            /* toda tag <p> */
.destaque    /* tudo com class="destaque" */
#topo        /* o elemento com id="topo" */
nav a        /* todo <a> dentro de <nav> */
a:hover      /* link quando o mouse está em cima */
button:focus /* botão quando está selecionado */
Dica: use class (.nome) para a maioria das coisas — pode repetir em vários elementos. Use id (#nome) só para algo único na página.

cssCores e fundo

.caixa {
  color: white;            /* cor do texto */
  background-color: #7B4FD0; /* cor de fundo */
  opacity: 0.9;            /* transparência 0 a 1 */
}
resultado
nomered, blue, tomato, teal... nomes prontos.
#RRGGBBhexadecimal: #F24487 (rosa), #08070E (quase preto).
rgb() / rgba()rgb(255,61,147) — o "a" adiciona transparência: rgba(0,0,0,.5).
background: linear-gradient(...)degradê: linear-gradient(#7B4FD0, #F24487).

.titulo {
  font-family: 'Space Grotesk', sans-serif;
  font-size: 32px;
  font-weight: 700;        /* 400 normal, 700 negrito */
  text-align: center;      /* left, center, right */
  line-height: 1.5;         /* altura da linha */
  letter-spacing: 1px;
  text-transform: uppercase; /* MAIÚSCULAS */
  text-decoration: underline;
}
resultado

cssBox model

Toda caixa tem 4 camadas, de dentro pra fora: content → padding → border → margin.

.card {
  width: 300px;
  padding: 20px;   /* espaço INTERNO */
  border: 2px solid #7B4FD0;
  border-radius: 12px; /* cantos arredondados */
  margin: 16px;    /* espaço EXTERNO */
  box-sizing: border-box; /* padding não estoura a largura */
}
resultado
Atalho de valores: padding: 10px 20px = 10 em cima/baixo, 20 nas laterais. Com 4 valores é no sentido horário: cima, direita, baixo, esquerda.

cssDisplay e posicionamento

display define como o elemento ocupa espaço. É a propriedade mais importante do CSS de layout.

display: blockocupa a linha inteira (div, p, h1). Empilha um embaixo do outro.
display: inlineocupa só o necessário, fica na mesma linha (span, a).
display: flexvira um container flexível — ver seção Flexbox.
display: gridvira uma grade — ver seção Grid.
display: nonesome da tela completamente.
.fixo-no-topo {
  position: sticky;  /* gruda ao rolar */
  top: 0;
  z-index: 10;      /* ordem de empilhamento */
}

cssFlexbox

O jeito moderno de alinhar itens em uma direção (linha ou coluna). Você aplica no container, e os filhos se organizam.

.container {
  display: flex;
  justify-content: space-between; /* eixo horizontal */
  align-items: center;         /* eixo vertical */
  gap: 16px;                    /* espaço entre itens */
}
resultado
flex-directionrow (linha, padrão) ou column (coluna).
justify-contentalinha no eixo principal: flex-start, center, space-between, space-around.
align-itemsalinha no eixo cruzado: center, flex-start, stretch.
gapespaço entre os itens.
flex-wrapwrap deixa quebrar linha quando não cabe.
Pratique jogando: flexboxfroggy.com ensina tudo isso movendo sapinhos. 🐸

cssGrid

Pra layouts em duas dimensões (linhas E colunas). Ótimo pra galerias e páginas inteiras.

.galeria {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 colunas iguais */
  gap: 12px;
}
resultado
Pratique jogando: cssgridgarden.com — regue as cenouras com CSS Grid. 🥕

cssEfeitos e transições

O tempero que deixa a interface viva: sombras, animações suaves e reação ao mouse.

.botao {
  background: #F24487;
  box-shadow: 0 8px 20px rgba(0,0,0,.2);
  transition: 0.2s;    /* suaviza mudanças */
  cursor: pointer;
}
.botao:hover {
  transform: translateY(-3px); /* sobe ao passar o mouse */
}
resultado (passe o mouse)

cssResponsividade e media queries

Um só código que funciona bem no celular, no tablet e no monitor. É o que separa um site amador de um profissional — e é mais simples do que parece.

Pré-requisito nº 1: sem esta linha no <head>, nada de responsivo funciona no celular. Ela manda o navegador respeitar o tamanho real da tela: 
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Unidades: fixas x flexíveis

Metade da responsividade é só parar de usar px pra tudo. Unidades relativas se ajustam sozinhas ao tamanho da tela e da fonte.

UnidadeO que éQuando usar
pxpixels fixos, não mudambordas, detalhes finos
%porcentagem do elemento pailarguras que acompanham o container
remrelativo à fonte base (1rem = 16px)tamanhos de fonte e espaçamentos — o queridinho
emrelativo à fonte do próprio elementopadding interno de botões
vw / vh1% da largura / altura da telaseções em tela cheia (100vh)
Truque profissional: width: min(600px, 90%) — o bloco tem no máximo 600px, mas nunca passa de 90% da tela. Responsivo numa linha só.

A sintaxe da media query

Uma media query é um "se a tela tiver tal tamanho, aplique estes estilos". Você coloca regras CSS normais lá dentro.

@media (min-width: 700px) {
  /* só vale quando a tela tem 700px OU MAIS */
  .menu { flex-direction: row; }
  .titulo { font-size: 48px; }
}

@media (max-width: 699px) {
  /* só vale quando a tela tem 699px OU MENOS */
  .esconder-no-celular { display: none; }
}
min-widthaplica de tal largura pra cima (abordagem mobile-first).
max-widthaplica de tal largura pra baixo.

Breakpoints comuns

"Breakpoint" é o tamanho onde o layout muda. Não existe regra fixa, mas estes são os pontos de virada mais usados:

até ~600px📱 celular — tudo empilhado, uma coluna
~600 a 900px📲 tablet — começa a caber lado a lado
~900px pra cima💻 desktop — layout completo, várias colunas

Mobile-first na prática

Escreva o estilo do celular primeiro (sem media query) e vá adicionando o que muda em telas maiores. É mais fácil e é como o mercado trabalha.

/* 1. base: celular — cards empilhados */
.cards {
  display: flex;
  flex-direction: column;
  gap: 12px;
}

/* 2. tela maior: coloca lado a lado */
@media (min-width: 700px) {
  .cards { flex-direction: row; }
}

Veja acontecer 👇

Clique nos tamanhos e observe o layout mudar. Em 700px a media query dispara e os blocos saem de empilhados pra lado a lado — sozinhos.

Bônus: grid que se vira sozinho

Esse padrão cria colunas que se ajustam sem nenhuma media query: cada card tem no mínimo 200px, e o grid encaixa quantos couberem por linha.

.galeria {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
E as imagens? Uma regra resolve 90% dos problemas: img { max-width: 100%; height: auto; } — a imagem nunca estoura a tela e mantém a proporção.
