Desafio · Aula 01

Seu primeiro site: sobre você 🚀

Chegou a sua vez! Você vai criar um site só seu, falando de você mesmo(a), usando HTML e CSS — exatamente o que a gente viu hoje. No final, ele vai estar publicado na internet com um link pra mandar pra todo mundo.

🎯

O objetivo

Uma página “Sobre mim”: sua foto (ou iniciais), quem você é, o que você curte, seus links — bonita e que funcione também no celular.

Passo a passo
01

Crie o arquivo

Crie uma pasta pro projeto (ex.: meu-site) e, dentro dela, um arquivo chamado index.html. Abra no VS Code.

Dica: o nome index.html é especial — é a página inicial que abre sozinha.

02

Monte o esqueleto HTML

Todo site começa com essa estrutura. Digite (não copie tudo — treinar a digitação ajuda a decorar!):

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meu site</title>
</head>
<body>

  <!-- seu conteúdo vem aqui -->

</body>
</html>
03

Escreva sobre você

Dentro do <body>, use as tags que aprendemos pra contar quem você é:

<h1>Seu Nome</h1>
<p>Uma frase sobre você. Ex: futura dev que ama <strong>café</strong>.</p>

<img src="foto.jpg" alt="Minha foto">

<h2>O que eu curto</h2>
<ul>
  <li>Música</li>
  <li>Jogos</li>
</ul>

<a href="https://github.com/seu-user">Meu GitHub</a>

Lembra: <h1> é o título, <p> parágrafo, <img> imagem, <ul>/<li> lista e <a> link.

04

Deixe bonito com CSS

No <head>, adicione um bloco <style> e dê cor e vida à página:

<style>
  body {
    font-family: sans-serif;
    background: #0f0c17;
    color: white;
    text-align: center;
  }
  h1 { color: #F24487; }
  img { width: 140px; border-radius: 50%; }
</style>

Experimente: troque as cores e veja o site mudar na hora.

05

Faça funcionar no celular

Adicione uma media query pra ajustar a página em telas pequenas:

@media (max-width: 480px) {
  h1 { font-size: 28px; }
}

Teste: aperte F12 no navegador e ative o modo celular.

06

Publique na internet

Suba o projeto pro GitHub e importe na Vercel — igual fizemos na aula. Em segundos você recebe um link do seu site no ar. 🌍

Meta final: mandar o link no grupo da turma!

Requisitos mínimos
  • Um título <h1> com o seu nome
  • Pelo menos um parágrafo <p> sobre você
  • Uma imagem <img> (foto, avatar ou desenho)
  • Uma lista <ul> com coisas que você gosta
  • Pelo menos um link <a> (rede social, GitHub…)
  • CSS com cores e fontes — nada de página branca sem graça 😄
  • Publicado na Vercel com link funcionando
Desafios extras (pra quem quer brilhar ✨)
  • Deixe a página responsiva de verdade com media queries
  • Faça um card de perfil centralizado, com sombra e cantos arredondados
  • Use um degradê rosa→roxo em algum lugar (tipo o nome)
  • Adicione um efeito de :hover nos links
  • Organize os hobbies num grid que se ajusta sozinho
