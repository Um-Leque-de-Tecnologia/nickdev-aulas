Código do desafio

O site “sobre mim” feito só com HTML e CSS, quebrado em pedaços e comentado. Junte tudo num arquivo index.html: a estrutura no <body> e o estilo dentro de <style> no <head>.

Combinado 🤝 Tente sozinho(a) primeiro. Use isto pra conferir depois ou estudar como cada parte funciona — não pra copiar antes de tentar.
🧱 Parte 1 · HTML — a estrutura

Esqueleto da página

Todo site começa assim. O <head> tem as configurações; o <body>, o conteúdo visível.

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Sobre mim</title>

  <style>
    /* todo o CSS da Parte 2 vai aqui */
  </style>
</head>
<body>

  <!-- todo o conteúdo abaixo vai aqui -->

</body>
</html>

Topo — foto + nome

A foto redonda (usando as iniciais) e o nome com o cargo.

<div class="container">

  <header class="topo">
    <!-- Com uma foto de verdade seria:
         <img class="foto" src="foto.jpg" alt="Minha foto"> -->
    <div class="foto">N</div>

    <h1>Nicoly Almeida</h1>
    <p class="cargo">Desenvolvedora & professora de tecnologia</p>
  </header>

Sobre mim

Um cartão com um parágrafo. <strong> deixa em negrito, <em> em itálico.

  <section class="card">
    <h2>Sobre mim</h2>
    <p>
      Oi! Eu <strong>ensino programação</strong> pra quem está
      começando na tech. Aprendo <em>fazendo</em>. 💜
    </p>
  </section>

Hobbies — uma lista

<ul> é a lista; cada <li> é um item.

  <section class="card">
    <h2>O que eu curto</h2>
    <ul>
      <li>Ensinar e ver a ficha caindo</li>
      <li>Café enquanto codo</li>
      <li>Design bonito e site rápido</li>
    </ul>
  </section>

Links

<a> é o link. href é pra onde vai; target="_blank" abre em nova aba.

  <section class="card">
    <h2>Onde me achar</h2>
    <div class="links">
      <a href="https://github.com/Nicoly-Almeida" target="_blank">GitHub</a>
      <a href="mailto:voce@email.com">E-mail</a>
    </div>
  </section>

</div> <!-- fecha o .container -->
🎨 Parte 2 · CSS — o estilo

Tudo isto vai dentro do <style>, lá no <head>.

Cores (variáveis)

Guardar as cores em variáveis deixa fácil trocar tudo depois.

:root {
  --rosa: #F24487;
  --roxo: #7B4FD0;
  --fundo: #0f0c17;
  --card: #1a1626;
  --texto: #f3f0fa;
  --texto-suave: #b4aec6;
}

Base — reset + body

O * zera margens de tudo; o body define fonte e cores gerais.

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;   /* padding soma por dentro */
}

body {
  font-family: 'Segoe UI', system-ui, sans-serif;
  background: var(--fundo);
  color: var(--texto);
  line-height: 1.6;
}

.container {
  max-width: 640px;      /* não estica demais */
  margin: 0 auto;        /* centraliza */
  padding: 48px 24px;
}

Foto redonda

border-radius: 50% deixa o quadrado virar círculo.

.topo { text-align: center; margin-bottom: 40px; }

.foto {
  width: 140px;
  height: 140px;
  border-radius: 50%;                 /* vira círculo */
  background: linear-gradient(135deg, var(--rosa), var(--roxo));
  /* centraliza as iniciais dentro */
  display: flex;
  align-items: center;
  justify-content: center;
  font-size: 58px;
  color: white;
  margin: 0 auto 20px;
}

Nome com degradê

Truque pra dar cor de degradê no texto (aquele efeito rosa→roxo).

h1 {
  font-size: 40px;
  background: linear-gradient(100deg, var(--rosa), var(--roxo));
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;              /* deixa o degradê aparecer */
}

.cargo { color: var(--texto-suave); font-size: 18px; }

Cards e seções

A barrinha colorida ao lado do título é um ::before.

.card {
  background: var(--card);
  border-radius: 16px;
  padding: 26px 28px;
  margin-bottom: 20px;
}

h2 { font-size: 22px; margin-bottom: 12px; }

/* barrinha de degradê antes do título */
h2::before {
  content: "";
  display: inline-block;
  width: 10px;
  height: 20px;
  background: linear-gradient(var(--rosa), var(--roxo));
  border-radius: 4px;
  margin-right: 10px;
  vertical-align: -3px;
}

Lista de hobbies

Tira as bolinhas padrão e põe uma setinha com ::before.

ul { list-style: none; margin-top: 6px; }

li {
  color: var(--texto-suave);
  padding: 8px 0;
  border-bottom: 1px solid rgba(255,255,255,0.07);
}
li::before { content: "→ "; color: var(--rosa); }

Links com hover

Vira botão em formato de pílula; muda de cor ao passar o mouse (:hover).

.links {
  display: flex;
  flex-wrap: wrap;      /* quebra linha se não couber */
  gap: 12px;
}
.links a {
  border: 1px solid rgba(255,255,255,0.2);
  padding: 10px 18px;
  border-radius: 100px;       /* pílula */
  text-decoration: none;
  color: var(--texto);
  transition: 0.2s;           /* hover suave */
}
.links a:hover {
  border-color: var(--rosa);
  color: var(--rosa);
}

Responsivo (media query)

Em telas pequenas (celular), diminui o nome e os espaços. Um dos desafios extras!

/* quando a largura for até 480px */
@media (max-width: 480px) {
  h1 { font-size: 32px; }
  .container { padding: 32px 18px; }
  .card { padding: 22px 20px; }
}
